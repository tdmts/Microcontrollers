Oplossing

Dit is een sinking-schakeling: de leds hangen met de anode aan een vaste +5V-rail en met de kathode (via de weerstand) aan de Arduino-pin. Er vloeit dus enkel stroom wanneer de pin LOW staat (de pin "zinkt" de stroom naar GND). Bij HIGH staat er geen spanningsverschil over de led en blijft hij uit. De code moet dus LOW gebruiken om een led aan te zetten, en HIGH om hem uit te zetten.

De frequentie van 1Hz slaat op de volledige cyclus van de 4 leds: elke led blijft dus 1000 / 4 = 250ms aan.

Het aan- en uitzetten van één led zit in laatBranden(), een functie met een parameter zoals je die in de begeleide oefening van labo 0 gemaakt hebt. Zo schrijf je die drie regels één keer in plaats van vier keer. 

const int led1 = 3;
const int led2 = 4;
const int led3 = 5;
const int led4 = 6;

const int stapDuur = 250; // 1000 ms gedeeld door 4 leds, dus 1Hz per cyclus

void setup()
{
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
  pinMode(led3, OUTPUT);
  pinMode(led4, OUTPUT);

  // sinking: HIGH = led uit, dus we beginnen met alles uit
  digitalWrite(led1, HIGH);
  digitalWrite(led2, HIGH);
  digitalWrite(led3, HIGH);
  digitalWrite(led4, HIGH);
}

void laatBranden(int pin)
{
  digitalWrite(pin, LOW); // sinking: LOW = led aan
  delay(stapDuur);
  digitalWrite(pin, HIGH); // sinking: HIGH = led uit
}

void loop()
{
  laatBranden(led1);
  laatBranden(led2);
  laatBranden(led3);
  laatBranden(led4);
}

Vier keer dezelfde regel in de loop() blijft wat omslachtig. Vanaf RGB Led leer je met arrays werken, en daarmee kort je dit soort herhaling in tot een lus van twee regels.
