Knight rider

Verbind 4 leds met pinnen 3 tot en met 6 en programmeer een looplicht maar dan met een knightrider effect. Frequentie is opnieuw 1Hz. Wat ga je moeten doen met de delay?

Schema

Vergelijk dit schema met dat van het looplicht. Wordt hier gebruik gemaakt van sourcing of sinking? Welke invloed heeft dat op de code?

Denk eerst zelf na en klap daarna open.

Sourcing of sinking?

Volg opnieuw de stroom op het schema. De anode van elke led hangt nu rechtstreeks aan een pin, en de kathode gaat via de weerstand naar de GND-rail. De stroom komt dus uit de pin en dat is sourcing, de omgekeerde bedrading van het looplicht.

De led brandt nu wanneer de pin HIGH is, want dan staat er 5V aan de anode en 0V aan de andere kant. Bij LOW staat er aan beide kanten 0V en blijft de led uit. Je zet een led dus aan met digitalWrite(pin, HIGH) en uit met digitalWrite(pin, LOW), precies omgekeerd aan je code van het looplicht.

Aan welke van de twee je toe bent, lees je dus af van je schema en niet van je code.

Hoe reken je de delay uit bij 1Hz?

De rekenweg is dezelfde als bij het looplicht: uit T = 1 / f volgt een periode van 1 s, ofwel 1000 ms voor één volledige cyclus. Die 1000 ms deel je door het aantal stappen in die cyclus.

Het aantal stappen is hier wel anders. Schrijf één cyclus uit tot je weer bij het begin bent: led 1, led 2, led 3, led 4, led 3, led 2 en dan opnieuw led 1. Dat zijn 6 stappen en geen 8, want led 1 en led 4 keren om en branden dus maar één keer per cyclus, terwijl led 2 en led 3 twee keer aan bod komen.

Per stap krijg je dan 1000 / 6 = 166,7 ms. Zowel 166 als 167 ms is goed, dat verschil van 1 ms ziet niemand.

Waar deze oefening haar naam vandaan heeft

Knight Rider is een Amerikaanse tv-serie uit 1982 over een pratende auto met de naam KITT. Die auto had vooraan een rode lichtbalk waarin het licht heen en weer schoof, en dat is het effect dat je hier nabouwt. Dezelfde producer had het vier jaar eerder al gebruikt voor de Cylons in Battlestar Galactica.

Oplossing

Het is een sourcing-schakeling, dus HIGH zet een led aan en LOW zet hem uit. Een volledige cyclus 1→2→3→4→3→2 bestaat uit 6 stappen, dus wordt de delay 1000 / 6 ≈ 166 ms in plaats van 1000 / 4.

Net als bij het looplicht kunnen we de oplossing in drie stappen opbouwen:

Stap 1: Volledig uitgeschreven (zonder functie)

Alle zes de stappen (vier heen, twee terug) schrijven we rechtstreeks in de loop(). 

const int led1 = 3;
const int led2 = 4;
const int led3 = 5;
const int led4 = 6;

// 6 stappen per cyclus (1->2->3->4->3->2), dus 1000 / 6 = 166 ms per stap
const int stapDuur = 166;

void setup()
{
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
  pinMode(led3, OUTPUT);
  pinMode(led4, OUTPUT);

  // sourcing: LOW = led uit, dus we beginnen met alles uit
  digitalWrite(led1, LOW);
  digitalWrite(led2, LOW);
  digitalWrite(led3, LOW);
  digitalWrite(led4, LOW);
}

void loop()
{
  // Heen
  digitalWrite(led1, HIGH); // sourcing: HIGH = led aan
  delay(stapDuur);
  digitalWrite(led1, LOW);  // sourcing: LOW = led uit

  digitalWrite(led2, HIGH);
  delay(stapDuur);
  digitalWrite(led2, LOW);

  digitalWrite(led3, HIGH);
  delay(stapDuur);
  digitalWrite(led3, LOW);

  digitalWrite(led4, HIGH);
  delay(stapDuur);
  digitalWrite(led4, LOW);

  // En terug, zonder de uiteinden te herhalen (led 3 en led 2)
  digitalWrite(led3, HIGH);
  delay(stapDuur);
  digitalWrite(led3, LOW);

  digitalWrite(led2, HIGH);
  delay(stapDuur);
  digitalWrite(led2, LOW);
}

Stap 2: Met een functie en parameter

Het aan- en uitzetten van één led gieten we in een eigen functie laatBranden(). In de loop() zie je de zes stappen dan onder elkaar staan, en meteen ook waarom het er zes zijn en geen acht: led 1 en led 4 komen maar één keer voor. 

const int led1 = 3;
const int led2 = 4;
const int led3 = 5;
const int led4 = 6;

// 6 stappen per cyclus (1->2->3->4->3->2), dus 1000 / 6 = 166 ms per stap
const int stapDuur = 166;

void setup()
{
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
  pinMode(led3, OUTPUT);
  pinMode(led4, OUTPUT);

  // sourcing: LOW = led uit, dus we beginnen met alles uit
  digitalWrite(led1, LOW);
  digitalWrite(led2, LOW);
  digitalWrite(led3, LOW);
  digitalWrite(led4, LOW);
}

void laatBranden(int pin)
{
  digitalWrite(pin, HIGH); // sourcing: HIGH = led aan
  delay(stapDuur);
  digitalWrite(pin, LOW); // sourcing: LOW = led uit
}

void loop()
{
  // Heen
  laatBranden(led1);
  laatBranden(led2);
  laatBranden(led3);
  laatBranden(led4);

  // En terug, zonder de uiteinden nog eens: anders zou de cyclus 8 stappen duren
  laatBranden(led3);
  laatBranden(led2);
}

Stap 3: Met for-lussen

Omdat de leds op opeenvolgende pinnen (3 t.e.m. 6) hangen, kun je twee for-lussen combineren: één die optelt van 3 naar 6 (heen), en één die aftelt van 5 naar 4 (terug). 

const int minPin = 3;
const int maxPin = 6;

// 6 stappen per cyclus (3->4->5->6->5->4), dus 1000 / 6 = 166 ms per stap
const int stapDuur = 166;

void setup()
{
  for (int pin = minPin; pin <= maxPin; pin++)
  {
    pinMode(pin, OUTPUT);
    digitalWrite(pin, LOW); // sourcing: LOW = led uit
  }
}

void laatBranden(int pin)
{
  digitalWrite(pin, HIGH); // sourcing: HIGH = led aan
  delay(stapDuur);
  digitalWrite(pin, LOW);  // sourcing: LOW = led uit
}

void loop()
{
  // Heen (pin 3 t.e.m. 6)
  for (int pin = minPin; pin <= maxPin; pin++)
  {
    laatBranden(pin);
  }

  // Terug (pin 5 en 4: we slaan de uiteinden 6 en 3 over)
  for (int pin = maxPin - 1; pin > minPin; pin--)
  {
    laatBranden(pin);
  }
}
