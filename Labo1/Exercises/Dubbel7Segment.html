Dubbel 7 segment

Gebruik een dubbel 7-segment display en laat de segmenten in een 8-animatie oplichten.

Het dubbel 7-segment vind je niet in de TinkerCad bibliotheek. Je kan onderstaand sjabloon gebruiken.

link 1: dubbel 7-segment sjabloon Tinkercad

link 2: sjabloon dubbel 7-segmentdisplay (tinkercad.com) (klik op copy and tinker)

Een 8-animatie betekent dat we segment per segment laten oplichten in een 8-vormige animatie: achtereenvolgens lichten segment a, b, g, e, d, c, g, f, ... op. Ieder segment blijft 1 seconde aan staan. Zoek eerst de layout en pinout op van een 7-segment display.

Oplossing

Let op: pas aan op basis van je eigen schema

De pinnummers hieronder zijn placeholders — vul ze aan met de pinnen die jij effectief gebruikt volgens het sjabloon dat je gekopieerd hebt. Of een segment aan gaat bij HIGH of bij LOW hangt af van of jouw display common anode of common cathode is — zoek dit op in de pinout/datasheet van je display en pas de constante SEGMENT_AAN hieronder aan.

De 8-vormige volgorde a → b → g → e → d → c → g → f doorloopt de acht in twee lussen (boven- en onderlus) die elkaar in het midden kruisen bij segment g, vandaar dat g twee keer in de reeks voorkomt. 

// Placeholder-pinnen: vervang door de pinnen uit jouw eigen schema
const int pinA = 2;
const int pinB = 3;
const int pinC = 4;
const int pinD = 5;
const int pinE = 6;
const int pinF = 7;
const int pinG = 8;

// Pas aan op basis van je display: HIGH voor common cathode, LOW voor common anode
const bool SEGMENT_AAN = HIGH;
const bool SEGMENT_UIT = !SEGMENT_AAN;

// Volgorde van de 8-animatie
const int volgorde[] = {pinA, pinB, pinG, pinE, pinD, pinC, pinG, pinF};
const int aantalStappen = sizeof(volgorde) / sizeof(volgorde[0]);

void setup() {
  int pins[] = {pinA, pinB, pinC, pinD, pinE, pinF, pinG};
  for (int i = 0; i < 7; i++) {
    pinMode(pins[i], OUTPUT);
    digitalWrite(pins[i], SEGMENT_UIT);
  }
}

void loop() {
  for (int i = 0; i < aantalStappen; i++) {
    digitalWrite(volgorde[i], SEGMENT_AAN);
    delay(1000); // elk segment 1 seconde aan
    digitalWrite(volgorde[i], SEGMENT_UIT);
  }
}
