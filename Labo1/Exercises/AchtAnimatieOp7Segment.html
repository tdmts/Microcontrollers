8-animatie op een 7-segment display

Je eerste display. Je begint met één segment, zoekt uit welk type display je hebt, en laat daarna de segmenten na elkaar oplichten in de vorm van een acht. Elk segment blijft 1 seconde aan.

Een 7-segment display is niets anders dan zeven leds in de vorm van een acht. Hoe ze heten en hoe ze aangesloten zijn, staat op Het 7-segment display. Lees dat eerst even door.

Begin met één segment

Sluit eerst alleen segment a aan, met zijn eigen voorschakelweerstand, en verbind de gemeenschappelijke pin volgens het schema van je display. Schrijf een sketchje dat die ene pin afwisselend hoog en laag zet, met een seconde ertussen.

Dat kleine programma beantwoordt meteen twee vragen die je verderop nodig hebt: welke Arduino-pin hangt effectief aan segment a, en gaat het segment branden bij HIGH of bij LOW?

Dan heb je een common anode display: de gemeenschappelijke pin hangt aan de +5V-rail, en een segment gaat pas branden wanneer de Arduino-pin die kant naar de massa trekt. Brandt het segment bij HIGH, dan is het een common cathode display en gaat de gemeenschappelijke pin naar GND.

Het is precies hetzelfde onderscheid als tussen sourcing en sinking uit labo 0, en als de omgekeerde logica die je bij Morsecode tegenkwam. Onthoud welk van de twee jij hebt, want de rest van deze oefening hangt ervan af.

Alle zeven segmenten

Sluit nu de overige zes segmenten aan, elk met zijn eigen weerstand. Noteer erbij welke Arduino-pin bij welk segment hoort, want dat heb je zo nodig.

Zeven keer pinMode uitschrijven mag, maar het kan korter. Zet de zeven pinnummers in een array en loop er met een for-lus overheen. Je hebt die array straks toch nodig.

De 8-animatie

Een 8-animatie laat de segmenten na elkaar oplichten alsof je met een pen een acht tekent, zonder je hand op te heffen: a, b, g, e, d, c, g, f en dan weer van voor af aan. Er brandt telkens maar één segment tegelijk, en elk segment blijft 1 seconde aan.

Waarom staat g twee keer in de reeks?

De acht bestaat uit twee lussen, een bovenste en een onderste, die elkaar in het midden kruisen. Dat kruispunt is segment g, en daar kom je dus twee keer voorbij: één keer op weg naar beneden en één keer op weg naar boven.

De volgorde is niet de pinvolgorde

Je hebt hier twee verschillende rijen nodig, en dat is makkelijk door elkaar te halen. De ene is "welke pin hoort bij welk segment", de andere is "in welke volgorde licht de animatie op". Zet ze in twee aparte arrays, dan blijft je code leesbaar.

Oplossing

Pas de pinnen en het niveau aan op jouw schakeling

De pinnummers hieronder zijn die van een display dat met segment a op pin 2 begint. Hangt het bij jou anders, pas dan de constanten bovenaan aan. Datzelfde geldt voor SEGMENT_AAN: die staat hier op LOW voor een common anode display, en moet HIGH zijn als het jouwe common cathode is.

Er staan twee arrays in deze oplossing, en ze doen echt iets anders. segPins zegt welke pin bij welk segment hoort en dient om alles in één lus als uitgang te zetten. animatie is de volgorde waarin de segmenten oplichten, en daar staat pinG twee keer in. 

const int pinA = 2;
const int pinB = 3;
const int pinC = 4;
const int pinD = 5;
const int pinE = 6;
const int pinF = 7;
const int pinG = 8;

// common anode: een segment brandt bij LOW. HIGH bij common cathode.
const bool SEGMENT_AAN = LOW;
const bool SEGMENT_UIT = !SEGMENT_AAN;

const int segPins[] = {pinA, pinB, pinC, pinD, pinE, pinF, pinG};
const int aantalSegmenten = sizeof(segPins) / sizeof(segPins[0]);

// De acht in één beweging: a, b, g, e, d, c, g, f
const int animatie[] = {pinA, pinB, pinG, pinE, pinD, pinC, pinG, pinF};
const int aantalStappen = sizeof(animatie) / sizeof(animatie[0]);

void setup()
{
  for (int i = 0; i < aantalSegmenten; i++)
  {
    pinMode(segPins[i], OUTPUT);
    digitalWrite(segPins[i], SEGMENT_UIT);
  }
}

void loop()
{
  for (int i = 0; i < aantalStappen; i++)
  {
    digitalWrite(animatie[i], SEGMENT_AAN);
    delay(1000);
    digitalWrite(animatie[i], SEGMENT_UIT);
  }
}
