8-animatie op een 7-segment display

Je eerste display en de eerste keer dat je gebruik maakt van arrays. Je begint met één segment aan te sturen en je laat daarna de segmenten na elkaar oplichten in de vorm van een acht. Elk segment blijft 1 seconde aan.

Een 7-segment display is zeven leds in de vorm van een acht. Jij gaat in deze oefening ieder segment apart aansturen. Dus eerst enkel segment a, dan enkel b, dan enkel c, enz.

Begin met één segment

Sluit eerst alleen segment a aan, met zijn eigen voorschakelweerstand, en verbind de gemeenschappelijke pin van het display met de GND. Schrijf een korte sketch die die ene pin HIGH zet. Als het segment gaat branden dan weet je dat je te maken hebt met een common cathode display. Indien het segment niet brandt dan verbind je de gemeenschappelijke pin met 5 Volt en zet je de pin LOW. Als het segment brandt, dan is het een common anode display.

Dat kleine programma beantwoordt meteen twee vragen die je verderop nodig hebt: welke Arduino-pin hangt effectief aan segment a, en gaat het segment branden bij HIGH of bij LOW?

Sourcing of sinking?

Bij een common cathode display hangt de gemeenschappelijke pin aan GND. De Arduino-pin levert stroom aan het segment (HIGH): dat is sourcing.

Bij een common anode display hangt de gemeenschappelijke pin aan 5V. De Arduino-pin trekt de stroom naar de massa (LOW): dat is sinking.

Alle zeven segmenten

Sluit nu de overige zes segmenten aan, elk met zijn eigen weerstand. Noteer erbij welke Arduino-pin bij welk segment hoort, want dat heb je zo nodig.

Zeven keer pinMode uitschrijven mag, maar het kan korter. Zet de zeven pinnummers in een array en loop er met een for-lus overheen. Je hebt die array straks toch nodig.

De 8-animatie

Een 8-animatie laat de segmenten na elkaar oplichten alsof je met een pen een acht tekent, zonder je hand op te heffen: a, b, g, e, d, c, g, f en dan weer van voor af aan. Er brandt telkens maar één segment tegelijk, en elk segment blijft 1 seconde aan.

Waarom staat g twee keer in de reeks?

De acht bestaat uit twee lussen, een bovenste en een onderste, die elkaar in het midden kruisen. Dat kruispunt is segment g, en daar kom je dus twee keer voorbij: één keer op weg naar beneden en één keer op weg naar boven.

Wat is de periode?

De periode T is de duur van één volledige animatiecyclus die steeds wordt herhaald. De animatie bestaat uit 8 stappen van 1 seconde (a, b, g, e, d, c, g, f), dus de periode is 8 × 1 s = 8 s.

Wat is de frequentie?

De relatie tussen frequentie en periode is f = 1 / T.

De frequentie van de animatiecyclus is hier dus 1 / 8 s = 0,125 Hz.

Oplossing

Pas de pinnen en het niveau aan op jouw schakeling

De pinnummers hieronder zijn die van een common cathode display op pinnen 2 tot en met 8. Heb je een common anode display, dan wissel je HIGH en LOW in je code om.

Op het schema hieronder gaat de gemeenschappelijke pin van het display naar de GND-rail, dus dit is een common cathode display. Elk segment hangt via zijn eigen voorschakelweerstand aan een pin tussen 2 en 8.

In deze oplossing gebruiken we minPin en maxPin in een for-lus in setup() om alle pinnen (2 tot en met 8) als uitgang in te stellen. De array animatie bevat de 8 stappen van de 8-vormige beweging (waarin pinG twee keer voorkomt). 

const int minPin = 2;
const int maxPin = 8;

const int pinA = 2;
const int pinB = 3;
const int pinC = 4;
const int pinD = 5;
const int pinE = 6;
const int pinF = 7;
const int pinG = 8;

// De acht in één beweging: a, b, g, e, d, c, g, f
const int animatie[] = {pinA, pinB, pinG, pinE, pinD, pinC, pinG, pinF};
const int aantalStappen = 8;

void setup()
{
  for (int pin = minPin; pin <= maxPin; pin++)
  {
    pinMode(pin, OUTPUT);
    digitalWrite(pin, LOW); // common cathode: LOW = segment uit
  }
}

void loop()
{
  for (int i = 0; i < aantalStappen; i++)
  {
    digitalWrite(animatie[i], HIGH); // common cathode: HIGH = segment aan
    delay(1000);
    digitalWrite(animatie[i], LOW);
  }
}
