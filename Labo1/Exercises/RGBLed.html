RGB Led

Plaats een RGB led op pinnen 3 (groen), 4 (blauw) en 5 (rood). Elke kleur moet 1 seconde zichtbaar zijn.

Stuur je de kleuren actief hoog of laag?

De RGB led is common cathode, dus de kleuren worden actief hoog aangestuurd.

Wat is de periode?

Een periode van een signaal is één volledige cyclus die steeds wordt herhaald. De eenheid is seconden. In dit geval is de periode 7 seconden.

Wat is de frequentie?

De relatie tussen frequentie en periode is als volgt: F = 1/T.

De frequentie is hier dus 1/7s ofwel ongeveer 0.143Hz

Schema

Zeven kleuren zijn zeven combinaties van de drie kleurkanalen (rood, groen en blauw). Met 3 geneste for-lussen doorloop je automatisch de binaire waarheidstabel van alle mogelijke combinaties, waarbij je de toestand waarin alle leds uit staan (0, 0, 0) overslaat.

Waarheidstabel van de RGB-kleurcombinaties
Rood (pin 5) Groen (pin 3) Blauw (pin 4) Resultaat / Kleur
0 0 0 Uit (overslaan)
0 0 1 Blauw
0 1 0 Groen
0 1 1 Cyaan (Groen + Blauw)
1 0 0 Rood
1 0 1 Magenta (Rood + Blauw)
1 1 0 Geel (Rood + Groen)
1 1 1 Wit (Rood + Groen + Blauw)

Oplossing

Volgens het schema is dit een common cathode RGB led: de gemeenschappelijke pin gaat rechtstreeks (zonder weerstand) naar de vaste GND-rail, en elk kleurkanaal gaat via zijn eigen weerstand naar een Arduino-pin. Dit is dus actief hoog: HIGH zet een kleurkanaal aan, LOW zet het uit.

De 7 basismengkleuren zijn alle combinaties van rood/groen/blauw behalve "alles uit": R, G, B, R+G (geel), G+B (cyaan), R+B (magenta) en R+G+B (wit). Elke combinatie blijft 1 seconde staan, dus de periode van 7 seconden klopt met de 7 kleuren uit de opgave hierboven. 

const int groenPin = 3;
const int blauwPin = 4;
const int roodPin = 5;

void setup()
{
  pinMode(groenPin, OUTPUT);
  pinMode(blauwPin, OUTPUT);
  pinMode(roodPin, OUTPUT);
}

void loop()
{
  // 3 geneste for-lussen doorlopen alle 8 combinaties van R/G/B (0 en 1)
  for (int r = 0; r <= 1; r++)
  {
    for (int g = 0; g <= 1; g++)
    {
      for (int b = 0; b <= 1; b++)
      {
        // Toestand (0,0,0) is "alles uit", die slaan we over
        if (r == 0 && g == 0 && b == 0)
        {
          continue;
        }

        digitalWrite(roodPin, r);
        digitalWrite(groenPin, g);
        digitalWrite(blauwPin, b);
        delay(1000); // elke kleur 1 seconde zichtbaar
      }
    }
  }
}
