Morsecode

Maak een nieuw programma. Plaats een rode led op pin 12 en schrijf een programma waarbij de led het woord SOS in morsecode weergeeft.

De schakeling van de morse decoder is beschikbaar via Tinkercad. Volg deze stappen om de schakeling te openen:

  1. Log in op Tinkercad.
  2. Ga naar Circuits.
  3. Zoek naar morse decoder HOGENT-ELM.
  4. Kopieer de schakeling.

Opgave

Morsecode bestaat uit korte signalen (punten) en lange signalen (strepen). De letter S bestaat uit drie punten, de letter O uit drie strepen. Om SOS te seinen laat je de led dus knipperen volgens het patroon S - O - S.

Hou hierbij rekening met de volgende timing:

  • Een punt duurt 0,1s, een streep duurt 0,3s.
  • Tussen twee punten/strepen binnen dezelfde letter zit een pauze van 0,1s.
  • Tussen twee letters zit een pauze van 0,3s.
  • Tussen twee woorden zit een pauze van 0,7s.

Gebruik lussen om je programma zo efficiënt mogelijk te maken. In de voorbeeldcode hieronder is de letter S al volledig uitgewerkt: vul zelf de O en de tweede S aan.

Voorbeeldcode

Lees de functie knipper() eerst eens aandachtig door voor je begint. Er staat iets in dat op het eerste gezicht omgekeerd lijkt aan wat je in labo 0 gebouwd hebt.

const int pinLed = 12;

const bool KORT = false;
const bool LANG = true;

void setup()
{
  pinMode(pinLed, OUTPUT);
}

void knipper(bool duur)
{
  digitalWrite(pinLed,LOW);
  delay(100);
  if(duur)
  {
    delay(200); //Extra delay
  }
  digitalWrite(pinLed,HIGH);
  delay(100);
}

void loop()
{
  //De letter S = 3x kort
  for(int i = 0; i < 3; i++)
  {
    knipper(KORT);
  }
  delay(300); //Pauze tussen twee letters.

  //Nu nog de O
  //...

  //Nu nog de S
  //...

}

Denk eens na over de niveaus

In de begeleide oefening van labo 0 liet digitalWrite(pin, HIGH) je led branden. Hier doet knipper() net het omgekeerde: de led gaat aan bij LOW en uit bij HIGH. Hoe kan dat, en wat zegt dat over de manier waarop de led in deze schakeling aangesloten is?

Deze schakeling is sinking. De led hangt met de anode aan de +5V-rail en met de kathode (via de weerstand) aan pin 12. Er staat dus pas spanning over de led wanneer de pin LOW is: de pin "zinkt" de stroom naar de massa. Bij HIGH staan beide kanten op 5 V, is er geen spanningsverschil, en blijft de led gedoofd.

In labo 0 hing de led er net andersom in, met de anode aan de pin: dat is sourcing, waarbij HIGH hem doet branden. Welke van de twee je hebt, lees je dus af van je schema en niet van je code. Zie Sourcen en sinken.

Zo'n actief lage schakeling kom je in dit vak nog vaak tegen, onder meer bij het 7-segment display met common anode en bij de I/O-expander in labo 4.

Oplossing

De letter O bestaat uit drie strepen, dus 3x knipper(LANG). Na elke letter volgt een pauze van 0,3s (al gegeven na de eerste S). Na de laatste letter is er geen "volgende letter" meer, maar omdat loop() meteen herbegint met een nieuwe S, wordt die pauze hier gebruikt als pauze tussen twee woorden (0,7s), anders zou de laatste S van dit SOS direct overlopen in de eerste S van de volgende herhaling. 

void loop()
{
  //De letter S = 3x kort
  for(int i = 0; i < 3; i++)
  {
    knipper(KORT);
  }
  delay(300); //Pauze tussen twee letters.

  //Nu nog de O
  for(int i = 0; i < 3; i++)
  {
    knipper(LANG);
  }
  delay(300); //Pauze tussen twee letters.

  //Nu nog de S
  for(int i = 0; i < 3; i++)
  {
    knipper(KORT);
  }
  delay(700); //Pauze tussen twee woorden (voor herhaling van SOS)
}
