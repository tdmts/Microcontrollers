Morsecode

Maak een nieuw programma. Plaats een rode led op pin 12 en schrijf een programma waarbij de led het woord SOS in morsecode weergeeft.

Opgave

Morsecode bestaat uit korte signalen (punten) en lange signalen (strepen). De letter S bestaat uit drie punten, de letter O uit drie strepen. Om SOS te seinen laat je de led dus knipperen volgens het patroon S - O - S.

Hou hierbij rekening met de volgende timing:

  • Een punt duurt 0,1s, een streep duurt 0,3s.
  • Tussen twee punten/strepen binnen dezelfde letter zit een pauze van 0,1s.
  • Tussen twee letters zit een pauze van 0,3s.
  • Tussen twee woorden zit een pauze van 0,7s.

Gebruik lussen om je programma zo efficiënt mogelijk te maken. In de voorbeeldcode hieronder is de letter S al volledig uitgewerkt: vul zelf de O en de tweede S aan.

Voorbeeldcode

Bekijk de code en lees vooral de functie knipper() eerst eens aandachtig door voor je begint.

const int ledPin = 12;

const bool KORT = false;
const bool LANG = true;

void setup()
{
  pinMode(ledPin, OUTPUT);
}

void knipper(bool duur)
{
  digitalWrite(ledPin, LOW); // led aan, want sinking
  delay(100);
  if (duur)
  {
    delay(200); //Extra delay
  }
  digitalWrite(ledPin, HIGH); // led uit
  delay(100);
}

void loop()
{
  //De letter S = 3x kort
  for (int i = 0; i < 3; i++)
  {
    knipper(KORT);
  }
  delay(200); //Pauze tussen twee letters: 300 ms in totaal, waarvan knipper() er al 100 gedaan heeft

  //Nu nog de O
  //...

  //Nu nog de S
  //...

}
Flashback naar labo 0

Alles wat in de voorbeeldcode staat, heb je in labo 0 al gezien:

  • Constanten voor het pinnummer, en het gegevenstype bool, dat enkel true of false kan bevatten.
  • pinMode() in setup(), en digitalWrite() om de pin hoog of laag te zetten.
  • Een eigen functie met een parameter. In de begeleide oefening gaf je knipper() een aantal en een duurtijd mee, hier krijgt hij één parameter duur.
  • Een enkelvoudige selectie met if, en de for-lus die de drie signalen van een letter herhaalt.

Denk eens na over de niveaus

In de begeleide oefening van labo 0 liet digitalWrite(pin, HIGH) je led branden. Hier doet knipper() net het omgekeerde: de led gaat aan bij LOW en uit bij HIGH. Hoe kan dat, en wat zegt dat over de manier waarop de led in deze schakeling aangesloten is?

Waarom brandt de led hier bij LOW?

Deze schakeling is sinking. De led hangt met de anode aan de +5V-rail en met de kathode (via de weerstand) aan pin 12. Er staat dus pas spanning over de led wanneer de pin LOW is: de pin "zinkt" de stroom naar de massa. Bij HIGH staan beide kanten op 5 V, is er geen spanningsverschil, en blijft de led gedoofd.

In labo 0 hing de led er net andersom in, met de anode aan de pin: dat is sourcing, waarbij HIGH hem doet branden. Welke van de twee je hebt, lees je dus af van je schema en niet van je code. Zie Sourcen en sinken.

Sluit je led dus zo aan: de anode aan de +5 V, de kathode aan een voorschakelweerstand van 220 Ω, en die weerstand aan pin 12. Welke poot de anode is, herken je met het ezelsbruggetje KNAP uit de begeleide oefening van labo 0: Kathode Negatief, Anode Positief.

Denk eens na over knipper()

De functie krijgt één parameter mee van het type bool. Roep je knipper(KORT) aan, dan komt er false binnen, en bij knipper(LANG) komt er true binnen.

Hoe lang brandt de led bij knipper(KORT) en bij knipper(LANG)?

Bij knipper(KORT) gaat de led aan, volgt er een delay(100), en gaat hij weer uit. Hij brandt dus 100 ms, en dat is de punt van 0,1s uit de opgave.

Bij knipper(LANG) is de voorwaarde van de if waar en komt er een delay(200) bij, terwijl de led ondertussen nog altijd aanstaat. Samen is dat 100 + 200 = 300 ms, de streep van 0,3s. Daarom staat die extra pauze binnen het stuk waarin de led brandt en niet erachter.

De laatste delay(100) valt na digitalWrite(ledPin, HIGH), dus terwijl de led uit is. Dat is de pauze van 0,1s tussen twee signalen van dezelfde letter. Elk signaal eindigt zelf al met die pauze, dus in je loop() hoef je er tussen twee punten of strepen geen meer te zetten.

Reken daar wel mee wanneer je de pauze tussen twee letters schrijft. Die moet 0,3s duren, en de laatste knipper() van de vorige letter heeft er al 0,1s van gedaan, dus zet je er nog 200 ms bij. Om dezelfde reden is de pauze tussen twee woorden 600 ms en geen 700.

Waarom staat er if (duur) en niet if (duur == true)?

Een if heeft een voorwaarde nodig die te herleiden is tot true of false. In labo 0 schreef je daar een vergelijking voor, zoals if (toestand == LOW): die vergelijking wordt eerst uitgerekend, en het resultaat is true of false. Zie Selecties.

duur is zelf al een bool en bevat dus al true of false. Er valt niets meer uit te rekenen, dus mag de naam er rechtstreeks staan. if (duur == true) doet precies hetzelfde.

De constanten KORT en LANG staan er om dezelfde reden als ledPin: knipper(LANG) zegt op de plaats van de oproep wat er gaat gebeuren, terwijl je bij knipper(true) in de functie moet gaan kijken wat true hier betekent.

Extra: morse met een buzzer

Je kan het SOS-signaal ook hoorbaar maken. In je Arduino-kit zitten daarvoor twee buzzers: een actieve en een passieve.

  • Een actieve buzzer heeft een oscillator ingebouwd, een schakeling die zelf een snel wisselend signaal opwekt. Zet je er spanning op, dan geeft hij één vaste toon. Aansturen doe je met digitalWrite(), net zoals bij een led.
  • Een passieve buzzer heeft die oscillator niet en zet alleen om wat je erop zet. Je moet dus zelf een wisselend signaal genereren. Dat doe je met tone(buzzerPin, 1000), waarbij buzzerPin de pin is waarop je de buzzer aansluit. Die pin gaat dan 1000 keer per seconde aan en uit. Met noTone(buzzerPin) leg je dat weer stil. Dat aantal keer per seconde heet de frequentie en wordt uitgedrukt in hertz (Hz). Hoe hoger het getal, hoe hoger de toon.

Voor deze oefening is de actieve buzzer direct bruikbaar. Een punt en een streep zijn ook hier een korte en een lange periode waarin de uitgang aanstaat, dus je hebt aan dezelfde knipper() genoeg.

Welke van de twee je in handen hebt, weet je door de buzzer kort tussen 5V en GND te hangen: de actieve zoemt onmiddellijk, de passieve geeft één klik en daarna stilte. Aan de behuizing zie je het meestal ook, want bij de passieve buzzer is de onderkant een open printplaat en bij de actieve is die dichtgemaakt. De actieve buzzer is gepolariseerd: net als bij een led maakt het uit hoe je hem in de schakeling hangt. De langere pin gaat naar de plus.

De led en de buzzer samen

De buzzer komt naast de led en niet in de plaats ervan, zodat je het SOS tegelijk ziet en hoort. Geef hem daarvoor een eigen pin, bijvoorbeeld pin 8, en laat de led op pin 12 staan.

Oplossing

De letter O bestaat uit drie strepen, dus 3x knipper(LANG). Na elke letter volgt een pauze van 0,3s (al gegeven na de eerste S). Daarvan zit er 0,1s al in knipper() zelf, dus blijft er 200 ms over om zelf te schrijven.

Na de laatste letter is er geen "volgende letter" meer, maar omdat loop() meteen herbegint met een nieuwe S, gebruik je die plaats voor de pauze tussen twee woorden. Anders zou de laatste S van dit SOS direct overlopen in de eerste S van de volgende herhaling. Die pauze duurt 0,7s, opnieuw min de 0,1s uit knipper(), dus 600 ms. 

const int ledPin = 12;

const bool KORT = false;
const bool LANG = true;

void setup()
{
  pinMode(ledPin, OUTPUT);
}

void knipper(bool duur)
{
  digitalWrite(ledPin, LOW); // led aan
  delay(100);
  if (duur)
  {
    delay(200); //Extra delay
  }
  digitalWrite(ledPin, HIGH); // led uit
  delay(100);
}

void loop()
{
  //De letter S = 3x kort
  for (int i = 0; i < 3; i++)
  {
    knipper(KORT);
  }
  delay(200); //Pauze tussen twee letters: 300 ms in totaal, waarvan knipper() er al 100 gedaan heeft

  //Nu nog de O
  for (int i = 0; i < 3; i++)
  {
    knipper(LANG);
  }
  delay(200); //Pauze tussen twee letters: 300 ms in totaal, waarvan knipper() er al 100 gedaan heeft

  //Nu nog de S
  for (int i = 0; i < 3; i++)
  {
    knipper(KORT);
  }
  delay(600); //Pauze tussen twee woorden: 700 ms in totaal, waarvan knipper() er al 100 gedaan heeft
}
