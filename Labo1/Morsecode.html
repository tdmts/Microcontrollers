Morsecode

Maak een nieuw programma. Plaats een rode LED op pin 12 en schrijf een programma waarbij de led het woord SOS in morsecode weergeeft.

Opgave

Morsecode bestaat uit korte signalen (punten) en lange signalen (strepen). De letter S bestaat uit drie punten, de letter O uit drie strepen. Om SOS te seinen laat je de LED dus knipperen volgens het patroon S - O - S.

Hou hierbij rekening met de volgende timing:

  • Een punt duurt 0,1s, een streep duurt 0,3s.
  • Tussen twee punten/strepen binnen dezelfde letter zit een pauze van 0,1s.
  • Tussen twee letters zit een pauze van 0,3s.
  • Tussen twee woorden zit een pauze van 0,7s.

Gebruik lussen om je programma zo efficiënt mogelijk te maken. In de voorbeeldcode hieronder is de letter S al volledig uitgewerkt: vul zelf de O en de tweede S aan.

Voorbeeldcode

const bool KORT = false;
const bool LANG = true;

void setup()
{
  pinMode(12, OUTPUT);
}

void knipper(bool duur) {
  digitalWrite(12,LOW);
  delay(100);
  if(duur) { delay(200); } //Extra delay
  digitalWrite(12,HIGH);
  delay(100);
}

void loop()
{
  //De letter S = 3x kort
  for(int i = 0; i < 3; i++)
  {
    knipper(KORT);
  }
  delay(300); //Pauze tussen twee letters.

  //Nu nog de O
  //...

  //Nu nog de S
  //...

}
