Morsecode

Maak een nieuw programma. Plaats een rode LED op pin 12 en schrijf een programma waarbij de led SOS in morsecode weergeeft.

Opgave

Een streep duurt 0,3s en een punt 0,1s. De pauze tussen strepen en punten is 0,1s. De pauze tussen twee letters is 0,3s en de pauze tussen twee woorden is 0,7s.

Tip: Efficiëntie

Gebruik lussen om het programma zo efficiënt mogelijk te maken. Bekijk de voorbeeldcode en vul aan.

Voorbeeldcode

const bool KORT = false;
const bool LANG = true;

void setup()
{
  pinMode(12, OUTPUT);
}

void knipper(bool duur) {
  digitalWrite(12,LOW);
  delay(100);
  if(duur) { delay(200); } //Extra delay
  digitalWrite(12,HIGH);
  delay(100);
}

void loop()
{
  //De letter S = 3x kort
  for(int i = 0; i < 3; i++)
  {
    knipper(KORT);
  }
  delay(300); //Pauze tussen twee letters.

  //Nu nog de O
  //...

  //Nu nog de S
  //...

}
