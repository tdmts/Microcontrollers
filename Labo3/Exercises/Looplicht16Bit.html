16-bit looplicht

Breid je 8-bit looplicht uit naar 16 bit met behulp van een extra schuifregister. Je Arduino gebruikt daarvoor geen enkele pin extra.

Plaats het tweede schuifregister in cascade, precies zoals bij 2x 7 segment display: Q7S van het eerste register naar DS van het tweede, en SHCP en STCP van beide registers aan elkaar. Op de acht uitgangen van het tweede register hangen dan acht extra LEDs, elk met hun eigen voorschakelweerstand.

Hoeveel moet je eigenlijk aanpassen?

Als je je 8-bit looplicht netjes met een lus hebt geschreven, is dit een heel korte oefening. Kijk eens waar het getal 8 in je code staat, en vraag je af of je het overal door een constante kan vervangen. Lukt dat, dan is je programma meteen ook klaar voor 24 of 32 bit.

Oplossing

Dit is exact dezelfde code als bij het 8-bit looplicht, met één verschil: aantalLeds staat nu op 16. Omdat de twee registers samen één lang schuifregister van 16 bits vormen, hoeft je programma niet te weten dat er twee IC's hangen. Je schuift gewoon 16 bits in plaats van 8 en latcht één keer.

De delay() gaat wel omlaag: met een seconde per stap zou één ronde 16 seconden duren en dat leest niet meer als een looplicht.

const int pinDS = 2;   // Data ingang van het eerste schuifregister
const int pinSTCP = 3; // 0 naar 1 = schuifregister naar storage register
const int pinSHCP = 4; // 0 naar 1 = seriële ingang naar schuifregister

// Twee schuifregisters in cascade vormen samen één register van 16 bits.
const int aantalLeds = 16;
const int stapTijd = 150; // ms per stap

void setup()
{
  pinMode(pinDS, OUTPUT);
  pinMode(pinSTCP, OUTPUT);
  pinMode(pinSHCP, OUTPUT);
}

void risingEdge(int pinNummer)
{
  digitalWrite(pinNummer, LOW);
  digitalWrite(pinNummer, HIGH);
}

void schuifBit(bool waarde)
{
  digitalWrite(pinDS, waarde ? HIGH : LOW);
  risingEdge(pinSHCP);
}

void loop()
{
  for (int j = 1; j <= aantalLeds; j++)
  {
    // De nullen boven de brandende LED
    for (int i = aantalLeds; i > j; i--)
    {
      schuifBit(false);
    }

    // De brandende LED zelf
    schuifBit(true);

    // En de nullen eronder
    for (int i = 1; i < j; i++)
    {
      schuifBit(false);
    }

    risingEdge(pinSTCP); // alle 16 LEDs tegelijk bijwerken
    delay(stapTijd);
  }
}
