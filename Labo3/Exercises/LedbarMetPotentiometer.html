Ledbar met potentiometer

Maak een schakeling waarbij de stand van een potentiometer op een analoge ingang wordt gelezen, en geef afhankelijk van de waarde een patroon weer op een schuifregister-ledbar.

Een ledbar is acht leds op een rij in één behuizing. Elektrisch verandert er dus niets tegenover de acht losse leds uit het 8-bit looplicht: elke led hangt met zijn eigen voorschakelweerstand aan een uitgang van het schuifregister. Let wel op de oriëntatie, want ook hier zitten alle anodes aan één kant en alle kathodes aan de andere.

Wat moet er branden?

Hoe verder je de potentiometer opendraait, hoe meer leds er oplichten:

Acht even brede stappen

Elk bereik in de tabel is even breed. Daarom volstaat één berekening om te bepalen hoeveel leds er moeten branden, in plaats van acht if-testen. Twijfel je over het uitlezen van de potentiometer, kijk dan bij analogRead().

De bedrading van het schuifregister blijft dezelfde als in de vorige oefeningen: DS op pin 2, STCP op pin 3 en SHCP op pin 4. De potentiometer komt op een analoge ingang, met de loper naar A0 en de twee buitenste aansluitingen naar de +5 V en de massa.

Oplossing

De acht bereiken zijn elk 128 breed, dus een gehele deling door 128 geeft je meteen een getal van 0 tot 7. Tel er 1 bij op en je hebt het aantal brandende leds.

Daarna schuif je acht bits naar buiten. Omdat de laatst verschoven bit op Q0 belandt, tel je af van 8 naar 1 en schuif je een 1 zodra het nummer van de led kleiner of gelijk is aan het gevraagde aantal.

const int pinDS = 2;   // Data ingang
const int pinSTCP = 3; // 0 naar 1 = schuifregister naar storage register
const int pinSHCP = 4; // 0 naar 1 = seriële ingang naar schuifregister
const int pinPot = A0; // Loper van de potentiometer

const int aantalLeds = 8;

void setup()
{
  pinMode(pinDS, OUTPUT);
  pinMode(pinSTCP, OUTPUT);
  pinMode(pinSHCP, OUTPUT);
}

void risingEdge(int pinNummer)
{
  digitalWrite(pinNummer, LOW);
  digitalWrite(pinNummer, HIGH);
}

void loop()
{
  // 0..1023 gedeeld door 128 geeft 0..7, dus +1 geeft 1 t.e.m. 8 LEDs
  int aantalAan = analogRead(pinPot) / 128 + 1;

  // De laatst verschoven bit komt op Q0, dus we tellen af van Q7 naar Q0
  for (int led = aantalLeds; led >= 1; led--)
  {
    digitalWrite(pinDS, led <= aantalAan ? HIGH : LOW);
    risingEdge(pinSHCP);
  }

  risingEdge(pinSTCP); // hele balk in één keer bijwerken
}
