Dimmer met schakelaar

Voeg een schakelaar toe aan je dimmer, zodat je de gedimde led ook aan en uit kan zetten.

Je vertrekt van de schakeling uit led dimmen met potentiometer. De potentiometer blijft de helderheid regelen, maar er komt een drukknop of schakelaar bij die de led volledig in- en uitschakelt.

Tip

Lees de schakelaar in met digitalRead(). Gebruik INPUT_PULLUP zodat je geen externe weerstand nodig hebt: de ingang is dan HIGH in rust en LOW wanneer je de knop indrukt.

Oplossing

De dimmer zelf blijft ongewijzigd: je leest de potentiometer in met analogRead() en herschaalt die waarde met map() naar 0 tot 255. Nieuw is dat je eerst de schakelaar uitleest. Staat die niet ingedrukt, dan schrijf je gewoon 0 naar de led in plaats van de berekende helderheid.

Met INPUT_PULLUP is de ingang LOW wanneer de knop ingedrukt is. Daarom controleer je op LOW en niet op HIGH. 

const int potPin = A0;    // potentiometer op analoge ingang A0
const int ledPin = 3;     // led op een PWM-pin (~)
const int knopPin = 2;    // schakelaar op digitale pin 2

void setup()
{
  pinMode(ledPin, OUTPUT);
  pinMode(knopPin, INPUT_PULLUP); // interne pull-up, knop schakelt naar massa
}

void loop()
{
  int potWaarde = analogRead(potPin);               // 0..1023
  int helderheid = map(potWaarde, 0, 1023, 0, 255); // herschaal naar 0..255

  if (digitalRead(knopPin) == LOW) // ingedrukt: led volgt de potentiometer
  {
    analogWrite(ledPin, helderheid);
  }
  else // niet ingedrukt: led uit
  {
    analogWrite(ledPin, 0);
  }
}
