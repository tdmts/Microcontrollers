Temperatuursensor LM35

Doe hetzelfde als bij de TMP36, maar nu met de LM35 uit je starterkit.

In je Arduino starterkit vind je een LM35. Dat is, net als de TMP36, een temperatuursensor. Maak nu zelf een programma waarbij je de temperatuur zichtbaar maakt in de seriële monitor. Het uitlezen met analogRead() en het omrekenen naar een spanning blijven hetzelfde.

Kijk goed naar de datasheet

De LM35 lijkt op de TMP36, maar hij rekent niet hetzelfde om. Zoek in de datasheet van de LM35 op welke spanning bij 0 °C op de uitgang staat, en hoeveel de spanning per graad toeneemt. Neem de formule van de TMP36 dus niet zomaar over.

Oplossing

De LM35 is eenvoudiger dan de TMP36: bij 0 °C staat er 0 V op de uitgang, en per graad komt er 10 mV bij. Je moet er dus niets van aftrekken en niets bij optellen, enkel delen door 0,01.

Precies daarom kan de LM35 geen temperaturen onder nul meten zonder extra schakeling: dat zou een negatieve spanning vragen, en die kan je Arduino niet inlezen. 

const int sensorPin = A0;

void setup()
{
  Serial.begin(9600);
}

void loop()
{
  int value = analogRead(sensorPin);        // 0..1023
  double spanning = value * 5.0 / 1023.0;   // omrekenen naar volt

  // de LM35 geeft 10 mV per graad, en 0 V bij 0 graden
  double temperatuur = spanning / 0.01;

  Serial.print(temperatuur);
  Serial.println(" graden C");

  delay(500);
}
