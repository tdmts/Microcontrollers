Temperatuurindicator met RGB-LED

Lees de temperatuur uit met de TMP36GT9Z, stuur ze naar de PC, en duid met een RGB-LED aan of ze te hoog, goed of te laag is.

De sensor en de omrekening zijn dezelfde als in de vorige oefeningen; de datasheet van de TMP35 / TMP36 / TMP37 kan je erbij houden. Gebruik de RGB-LED om de toestand aan te duiden:

  • Rood: temperatuur is te hoog (hoger dan 30 °C)
  • Groen: temperatuur is OK (vanaf 20 °C tot en met 30 °C)
  • Blauw: temperatuur is te laag (lager dan 20 °C)
Bouw verder op wat je al hebt

Het uitlezen en omrekenen van de sensor is hetzelfde als bij Temperatuursensor TMP36, en de RGB-LED stuur je aan zoals in RGB-LED uit labo 1. Het nieuwe stuk is enkel de koppeling tussen de twee.

Oplossing

Het valt uiteen in drie stukjes: uitlezen en omrekenen, beslissen welke kleur erbij hoort, en die kleur tonen. Door het tonen in een eigen functie toonKleur() te zetten, schakel je altijd eerst alle drie de kleuren uit voor je er één aanzet. Zo kan er nooit een oude kleur blijven meebranden.

Let op de volgorde van je if-testen. Omdat je na de eerste test die klopt stopt, hoef je in de tweede test niet nog eens te controleren of de temperatuur onder de 30 zit: dat weet je dan al. 

const int sensorPin = A0;

const int roodPin = 3;
const int groenPin = 4;
const int blauwPin = 5;

const double teHoog = 30.0;
const double teLaag = 20.0;

void setup()
{
  pinMode(roodPin, OUTPUT);
  pinMode(groenPin, OUTPUT);
  pinMode(blauwPin, OUTPUT);
  Serial.begin(9600);
}

void toonKleur(bool rood, bool groen, bool blauw)
{
  digitalWrite(roodPin, rood);
  digitalWrite(groenPin, groen);
  digitalWrite(blauwPin, blauw);
}

double leesTemperatuur()
{
  int value = analogRead(sensorPin);        // 0..1023
  double spanning = value * 5.0 / 1023.0;   // omrekenen naar volt

  // 0,75 V komt overeen met 25 graden, en elke graad erbij is 0,01 V erbij
  return (spanning - 0.75) / 0.01 + 25.0;
}

void loop()
{
  double temperatuur = leesTemperatuur();

  Serial.print(temperatuur);
  Serial.println(" graden C");

  if (temperatuur > teHoog)
  {
    toonKleur(true, false, false);  // rood
  }
  else if (temperatuur >= teLaag)
  {
    toonKleur(false, true, false);  // groen
  }
  else
  {
    toonKleur(false, false, true);  // blauw
  }

  delay(500);
}
