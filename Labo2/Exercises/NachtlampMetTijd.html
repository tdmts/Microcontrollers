Nachtlamp met tijd

Maak een nachtlamp die de LED inschakelt zodra het donker wordt, maar ze na 10 seconden weer uitschakelt.

De nachtlamp gaat automatisch uit wanneer het opnieuw licht wordt. Je bouwt verder op de LDR-schakeling uit LDR: lichtmeting.

Tip: gebruik geen delay()

Je zou je er makkelijk vanaf kunnen maken met delay(10000), maar daarmee blokkeer je je hele programma: tijdens die 10 seconden kan je niets meer inlezen. Vraag gerust uitleg tijdens het labo als dat nog niet duidelijk is.

Non-blocking timer

Met millis() vraag je op hoeveel milliseconden je Arduino al aan het werk is. Je kwam die aanpak al tegen bij Debouncen in labo 0 en bij het multiplexen in labo 1. Door de huidige tijd te vergelijken met een eerder bewaard tijdstip laat je tijd verstrijken zonder je programma stil te leggen:

unsigned long previousMillis;
const unsigned long interval = 10000; // 10 seconden

void setup()
{
  Serial.begin(9600);
}

void loop()
{
  unsigned long currentMillis = millis(); // huidige tijd

  if (currentMillis - previousMillis >= interval)
  {
    // voer acties uit die elk interval uitgevoerd moeten worden

    previousMillis = currentMillis; // onthoud wanneer het interval verstreek
  }
  else
  {
    // voer acties uit die sowieso uitgevoerd moeten worden
  }
}

Oplossing

Je houdt met een bool bij of de lamp brandt, en met een unsigned long wanneer ze precies is aangegaan. Zodra het donker wordt en de lamp nog niet brandt, schakel je ze in en noteer je het tijdstip. In elke doorloop van loop() controleer je daarna twee dingen: of de 10 seconden om zijn, en of het intussen weer licht is geworden.

De variabele lampAanSinds is een unsigned long omdat millis() dat ook is. Zet je die in een gewone int, dan loopt hij na iets meer dan 32 seconden over en klopt je timing niet meer. 

const int ldrPin = A0; // midden van de spanningsdeler op A0
const int ledPin = 3;  // led, zelfde pin als in de vorige oefening

const int drempel = 400;                  // onder deze waarde noemen we het donker
const unsigned long brandduur = 10000;    // 10 seconden

bool lampBrandt = false;
unsigned long lampAanSinds = 0;

void setup()
{
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop()
{
  int licht = analogRead(ldrPin);
  unsigned long nu = millis();

  if (!lampBrandt && licht < drempel) // het wordt donker: lamp aan
  {
    digitalWrite(ledPin, HIGH);
    lampBrandt = true;
    lampAanSinds = nu;
  }
  else if (lampBrandt)
  {
    bool tijdOm = (nu - lampAanSinds) >= brandduur;
    bool weerLicht = licht >= drempel;

    if (tijdOm || weerLicht) // uit na 10 seconden, of zodra het licht wordt
    {
      digitalWrite(ledPin, LOW);
      lampBrandt = false;
    }
  }
}
