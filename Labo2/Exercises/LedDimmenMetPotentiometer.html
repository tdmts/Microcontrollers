LED dimmen met potentiometer

Maak een dimmer waarbij de potentiometer de LED regelt.

Plaats eventueel ook een kleine weerstand (bijvoorbeeld 100 Ohm) in serie met de potentiometer zodat je bij verkeerd schakelen niets kapot maakt.

Oplossing

Je leest de potentiometer in met analogRead(), wat een waarde tussen 0 en 1023 oplevert. analogWrite() verwacht echter een waarde tussen 0 en 255, dus herschaal je de gelezen waarde met map() voor je ze naar de led stuurt. De led moet op een PWM-pin hangen (aangeduid met een ~, bijvoorbeeld pin 3). 

const int potPin = A0; // potentiometer op analoge ingang A0
const int ledPin = 3;  // led op een PWM-pin (~)

void setup()
{
  pinMode(ledPin, OUTPUT);
}

void loop()
{
  int potWaarde = analogRead(potPin);               // 0..1023
  int helderheid = map(potWaarde, 0, 1023, 0, 255); // herschaal naar 0..255
  analogWrite(ledPin, helderheid);
}
