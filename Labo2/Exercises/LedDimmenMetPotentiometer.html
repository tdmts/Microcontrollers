LED dimmen met potentiometer

Maak een dimmer waarbij de potentiometer de LED regelt.

Je combineert hier de twee vorige oefeningen: analogRead() om de potentiometer te lezen, en analogWrite() om de led te dimmen. Plaats eventueel ook een kleine weerstand (bijvoorbeeld 100 Ohm) in serie met de potentiometer zodat je bij verkeerd schakelen niets kapot maakt.

Twee bereiken die niet op elkaar passen

Er zit een addertje onder het gras. analogRead() geeft je een waarde tussen 0 en 1023, maar analogWrite() verwacht er een tussen 0 en 255. Stuur je de gelezen waarde rechtstreeks door, dan staat je led al op vol vermogen zodra de potentiometer een kwart gedraaid is, en verandert er daarna niets meer.

Je moet de waarde dus herschalen: het bereik 0 tot 1023 uitrekken of samendrukken tot 0 tot 255. Daar bestaat een functie voor:

long resultaat = map(waarde, vanLaag, vanHoog, naarLaag, naarHoog);

Je geeft de waarde mee die je wil omzetten, dan de onder- en bovengrens van het bereik waar ze uit komt, en dan die van het bereik waar ze naartoe moet. Voor deze oefening wordt dat dus map(potWaarde, 0, 1023, 0, 255).

map() kan ook omkeren

Niets verplicht je om het uitvoerbereik oplopend te schrijven. Draai je de laatste twee om, dan keert de richting mee om: een hoge invoerwaarde geeft dan een lage uitvoerwaarde. Dat heb je verderop nodig bij de LDR. Meer voorbeelden staan op map().

Oplossing

Je leest de potentiometer in met analogRead(), wat een waarde tussen 0 en 1023 oplevert. analogWrite() verwacht echter een waarde tussen 0 en 255, dus herschaal je de gelezen waarde met map() voor je ze naar de led stuurt. De led moet op een PWM-pin hangen (aangeduid met een ~, bijvoorbeeld pin 3). 

const int potPin = A0; // potentiometer op analoge ingang A0
const int ledPin = 3;  // led op een PWM-pin (~)

void setup()
{
  pinMode(ledPin, OUTPUT);
}

void loop()
{
  int potWaarde = analogRead(potPin);               // 0..1023
  int helderheid = map(potWaarde, 0, 1023, 0, 255); // herschaal naar 0..255
  analogWrite(ledPin, helderheid);
}
