analogWrite

Met analogWrite() kan je een analoge spanning simuleren op bepaalde pinnen van je Arduino. Dit noemen we PWM (Pulse Width Modulation).

Hoe werkt het?

PWM werkt door een digitaal signaal heel snel aan en uit te zetten. Dit gebeurt ongeveer 490 keer per seconde (490 Hz) op een Arduino Uno of Leonardo. Door de verhouding tussen "aan tijd" en "uit tijd" te variëren, kan je bijvoorbeeld een led dimmen of de snelheid van een motor regelen.

Je geeft in de functie analogWrite een waarde mee tussen 0 en 255:

  • 0 = altijd uit (0% duty cycle, 0V gemiddeld)
  • 127 = 50% van de tijd aan (50% duty cycle, ~2.5V gemiddeld)
  • 255 = altijd aan (100% duty cycle, 5V)

De resolutie (het aantal mogelijke toestanden) is bij analogWrite slechts 256 (en niet 1024 zoals bij analogRead het geval is). Dit komt omdat hier 8 bits worden gebruikt (2^8 = 256) in plaats van 10 bits.

Voorbeeld

const int potPin = A0;  // Potentiometer op analoge pin A0
const int ledPin = 3;   // LED op PWM pin 3

void setup()
{
  pinMode(ledPin, OUTPUT);
}

void loop()
{
  // Lees de potentiometer uit (0-1023)
  int potWaarde = analogRead(potPin);

  // Herschaal naar PWM waarde (0-255)
  int helderheid = potWaarde / 1023.0 * 255;

  // Stuur PWM signaal naar LED
  analogWrite(ledPin, helderheid);
}
PWM werkt alleen op de pinnen met een ~

Op de Arduino Uno en Leonardo zijn dat de pinnen met een ~ symbool ernaast (pin 3, 5, 6, 9, 10, 11). De andere pinnen ondersteunen geen PWM.

Waarom autolichten soms flikkeren op video

Achteraan een auto zit dezelfde lamp in twee rollen: zwak als achterlicht, fel als remlicht. Dat verschil in helderheid maakt de fabrikant met PWM. Je oog volgt dat schakelen niet, maar een camera neemt beeld voor beeld op en valt daarbij soms in een uit-periode, waardoor je op de opname strepen of geflikker ziet die er in het echt niet zijn.
