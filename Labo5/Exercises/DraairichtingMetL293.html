Draairichting omkeren met de L293D

Lees de potentiometer uit en stuur een L293D zodanig aan dat de motor naar links draait bij een waarde kleiner dan 512, en naar rechts vanaf 512. Eén knop, twee richtingen.

Met de transistor uit de vorige oefening kwam je niet verder dan aan en uit: die ene transistor laat de stroom maar op één manier door de motor. Om te keren moet je de twee draden kunnen omwisselen, en daar dient een H-brug voor. Lees die pagina door voor je begint, want je hebt er de pinout van de L293D bij nodig.

Deze oefening werk je uit in TinkerCAD.

Het schema

Wat waar aan hangt
Arduino L293D Waarvoor
pin 3 1,2EN (pin 1) Zet de brug aan
pin 4 1A (pin 2) Samen bepalen ze de richting
pin 5 2A (pin 7)
A0 - De potentiometer

De motor hangt tussen 1Y (pin 3 van het IC) en 2Y (pin 6). Vcc1 krijgt 5 V voor de logica, Vcc2 de spanning voor de motor, en de vier massapinnen gaan allemaal naar GND.

Hang de enable op pin 3 en laat hem daar staan

Voor deze oefening volstaat een gewone digitalWrite(HIGH) op de enable, dus je zou er elke pin voor kunnen nemen. Pin 3 is er eentje met een ~, en dat heb je in de volgende oefening nodig om er met analogWrite() de snelheid mee te regelen. Zet hem dus meteen goed, dan hoef je straks geen draad te verleggen.

Wat je moet programmeren

Lees de potentiometer uit en vergelijk de waarde met 512, de helft van het bereik. Onder die grens stuur je de ene richting, erboven de andere. Welke combinatie van 1A en 2A welke richting geeft, staat in de tabel op De H-brug.

Oplossing

De enable gaat één keer hoog in de setup() en blijft daar. In de loop() hoef je dan alleen nog te kiezen welke van de twee ingangen hoog staat.

De grenswaarde 512 staat als constante bovenaan. Zo hoef je maar op één plaats te zoeken als je ze wil verleggen, en de if leest als een zin.

const int enablePin = 3; // 1,2EN van de L293D
const int in1Pin = 4;    // 1A
const int in2Pin = 5;    // 2A

const int potPin = A0;

const int grens = 512;

void setup()
{
  pinMode(enablePin, OUTPUT);
  pinMode(in1Pin, OUTPUT);
  pinMode(in2Pin, OUTPUT);

  digitalWrite(enablePin, HIGH); // brug altijd actief
}

void loop()
{
  int potWaarde = analogRead(potPin);

  if (potWaarde < grens)
  {
    // naar links
    digitalWrite(in1Pin, LOW);
    digitalWrite(in2Pin, HIGH);
  }
  else
  {
    // naar rechts
    digitalWrite(in1Pin, HIGH);
    digitalWrite(in2Pin, LOW);
  }
}
