Stappenmotor van richting doen keren met een drukknop

Voeg een drukknop toe die de draairichting omkeert. Elke keer dat je hem indrukt draait de motor de andere kant op. De knop gedraagt zich dus als een eindeloopschakelaar: hij meldt niet "ga naar links", hij meldt "je bent aan het einde, keer om".

Je vertrekt van je programma uit Wisselen tussen full step en half step. Er komt één drukknop bij, op een vrije pin.

Achteruit door de tabel

De andere kant op draaien is niet moeilijker dan de stappentabel omgekeerd doorlopen. Waar je nu optelt, ga je aftrekken.

Pas op met de restoperator en negatieve getallen

Sta je op stap 0 en trek je er 1 af, dan kom je op -1 uit. In C++ geeft -1 % 8 niet 7 maar -1, en dan lees je buiten je array. Wat daar staat weet niemand, en je programma doet vanaf dan onvoorspelbare dingen.

Tel er daarom eerst het aantal stappen bij op voor je de rest neemt: (huidigeStap - stapGrootte + aantalStappen) % aantalStappen. Nu blijft de teller altijd positief.

Een drukknop is geen schuifschakelaar

Bij de schuifschakelaar van de vorige oefening las je gewoon de stand uit. Een drukknop werkt anders: je wil reageren op het moment dat hij ingedrukt wordt, niet op het feit dat hij ingedrukt blijft. Lees je alleen de stand uit, dan keert je motor om bij elke ronde van de loop() zolang je je vinger op de knop houdt. Bij een loop() die duizenden keren per seconde draait, staat de motor dan gewoon te trillen.

Je hebt dus twee dingen nodig die je allebei al kent:

  • Flankdetectie: onthoud de vorige stand van de knop en reageer alleen wanneer die van los naar ingedrukt gaat. Datzelfde deed je in labo 4 bij het inlezen van de drukknoppen.
  • Debouncen: een mechanisch contact stuitert bij het sluiten, dus één druk levert een handvol flanken op. Zonder ontdendering keert je motor per druk een willekeurig aantal keren om, en dat ziet er precies uit als "hij doet soms niets".
Werkt het niet meteen? Bouw het in twee stappen

Vervang de drukknop eerst even door een schuifschakelaar, waarbij de ene stand links betekent en de andere rechts. Dan test je alleen of het achteruit doorlopen van je tabel klopt. Werkt dat, zet de drukknop er dan pas bij, zodat je zeker weet dat een probleem in de knop zit en niet in je richtinglogica.

Oplossing

De richting zit in één variabele die 1 of -1 is. Bij een druk op de knop draai je gewoon het teken om met richting = -richting, en de rest van je programma merkt er niets van.

De knop wordt hier ontdenderd met millis(): een nieuwe flank telt pas mee als de vorige minstens 50 ms geleden is. Dat is dezelfde aanpak als in labo 0, en ze houdt de loop() vrij zodat de motor gewoon blijft draaien terwijl je wacht.

De knop hangt hier op INPUT_PULLUP, dus hij leest LOW wanneer je hem indrukt. Dan heb je geen aparte weerstand nodig.

const int motorPinnen[] = {2, 3, 4, 5}; // 1A, 2A, 3A, 4A van de L293D
const int modusPin = 6;                 // schuifschakelaar: full of half step
const int knopPin = 7;                  // drukknop: keert de richting om
const int potPin = A0;

const int aantalStappen = 8;
const unsigned long ontdenderTijd = 50; // ms

// De half-steptabel. Stap 0, 2, 4 en 6 zijn samen de full-steptabel.
const int halfStep[aantalStappen][4] = {
  {1, 0, 0, 0}, // alleen spoel A
  {1, 0, 1, 0}, // A en B samen
  {0, 0, 1, 0}, // alleen spoel B
  {0, 1, 1, 0}, // A en B samen
  {0, 1, 0, 0}, // alleen spoel A
  {0, 1, 0, 1}, // A en B samen
  {0, 0, 0, 1}, // alleen spoel B
  {1, 0, 0, 1}  // A en B samen
};

int huidigeStap = 0;
int richting = 1; // 1 is vooruit, -1 is achteruit

int vorigeKnopStand = HIGH;
unsigned long laatsteFlank = 0;

void zetStap(int stap)
{
  for (int pin = 0; pin < 4; pin++)
  {
    digitalWrite(motorPinnen[pin], halfStep[stap][pin]);
  }
}

void setup()
{
  for (int pin = 0; pin < 4; pin++)
  {
    pinMode(motorPinnen[pin], OUTPUT);
  }

  pinMode(modusPin, INPUT);
  pinMode(knopPin, INPUT_PULLUP); // knop leest LOW als je hem indrukt
}

void loop()
{
  int knopStand = digitalRead(knopPin);

  // alleen reageren op de flank van los naar ingedrukt
  if (knopStand == LOW && vorigeKnopStand == HIGH)
  {
    if (millis() - laatsteFlank > ontdenderTijd)
    {
      richting = -richting;
      laatsteFlank = millis();
    }
  }

  vorigeKnopStand = knopStand;

  int potWaarde = analogRead(potPin);
  int wachttijd = map(potWaarde, 0, 1023, 100, 2);

  int stapGrootte = 1;

  if (digitalRead(modusPin) == LOW)
  {
    stapGrootte = 2; // full step: de tussenstanden overslaan
  }

  zetStap(huidigeStap);
  delay(wachttijd);

  // + aantalStappen zodat de teller nooit negatief wordt
  huidigeStap = (huidigeStap + richting * stapGrootte + aantalStappen) % aantalStappen;
}
Die delay() is eigenlijk al te veel

Zolang de delay() loopt, leest je programma de knop niet. Zet je de motor traag, dan kan je een korte druk missen. Netter is het om ook de stappen op millis() te laten lopen in plaats van op delay(), precies zoals je bij de nachtlamp in labo 2 gedaan hebt. Probeer het eens.
