Zacht omkeren met de L293D

Je vorige programma werkt, en toch deugt het niet. In deze oefening bouw je het om zodat de potentiometer niet alleen de richting bepaalt maar ook de snelheid, en de motor dus vloeiend afremt, stilvalt en de andere kant op vertrekt.

Wat was er mis met de vorige oefening?

Het programma van Draairichting omkeren met de L293D doet exact wat er gevraagd werd. Toch zou je het zo nooit op een echte machine zetten.

Die motor draait aan 10000 toeren naar links. Je schuift de potentiometer één stapje voorbij 512, en van de ene lus op de andere keert de stroom volledig om. De motor moet dus in één klap van 10000 toeren links naar 10000 toeren rechts.

Mechanisch is dat een schok waar een tandwielkast of een koppeling niet tegen kan. Elektrisch is het nog erger: een motor die nog draait terwijl je de spanning omkeert werkt even als een generator die tegenwerkt, en de stroompiek die daardoor loopt is een veelvoud van de normale bedrijfsstroom. Je H-brug krijgt die rekening.

Wat je wil, is dat de motor afremt naar nul voor hij de andere kant op vertrekt. En dat is precies wat je krijgt als je met dezelfde knop ook de snelheid regelt.

De opdracht

Bouw je programma om zodat de potentiometer over zijn hele bereik werkt als een gaspedaal met twee richtingen:

Stand van de potentiometer Wat de motor doet
0 Voluit naar links
rond 512, in het midden Stil
1023 Voluit naar rechts

De richting haal je nog altijd uit de vergelijking met 512. Nieuw is de snelheid: hoe ver de knop van het midden af staat, bepaalt hoe hard de motor draait.

Waar zet je die PWM?

Niet op 1A of 2A: die twee bepalen de richting, en daar moet gewoon een vaste HIGH en LOW op staan. De snelheid regel je op de enable, met analogWrite(). Staat de enable half van de tijd hoog, dan krijgt de motor gemiddeld de helft van de spanning.

Dan moet die enable wel op een pin met een ~ hangen

Hier zie je waarom de vorige oefening je de enable meteen op pin 3 liet zetten. Op de UNO werkt analogWrite() alleen op pin 3, 5, 6, 9, 10 en 11. Zet je hem op een pin zonder ~, dan compileert alles vrolijk en gedraagt je motor zich alsof je gewoon digitalWrite() gebruikt: elke waarde vanaf 128 is voluit, alles eronder is stil. Dat is een fout die je aan je code niet ziet.

Je hebt twee bereiken die allebei op 0 tot 255 moeten uitkomen: 511 terug naar 0 voor de ene kant, en 512 door naar 1023 voor de andere. Met twee keer een map(), elk in zijn eigen tak van de if, ben je er.

Let op de richting van je eerste map: bij een potwaarde van 0 wil je 255 als snelheid, en bij 511 wil je 0. Dat mag, map() aanvaardt een omgekeerd bereik gewoon.

Oplossing

De if doet nu twee dingen tegelijk: hij zet de richting én rekent uit hoe ver de knop van het midden af staat. Die afstand komt in snelheid terecht, en die zet je op de enable.

Merk op dat de eerste map() van 511 naar 0 loopt en niet omgekeerd. Hoe kleiner de potwaarde, hoe verder van het midden, hoe sneller de motor.

const int enablePin = 3; // 1,2EN van de L293D, moet een PWM-pin zijn
const int in1Pin = 4;    // 1A
const int in2Pin = 5;    // 2A

const int potPin = A0;

const int midden = 512;

void setup()
{
  pinMode(enablePin, OUTPUT);
  pinMode(in1Pin, OUTPUT);
  pinMode(in2Pin, OUTPUT);
}

void loop()
{
  int potWaarde = analogRead(potPin);
  int snelheid = 0;

  if (potWaarde < midden)
  {
    // naar links, en hoe lager de waarde hoe sneller
    digitalWrite(in1Pin, LOW);
    digitalWrite(in2Pin, HIGH);
    snelheid = map(potWaarde, midden - 1, 0, 0, 255);
  }
  else
  {
    // naar rechts, en hoe hoger de waarde hoe sneller
    digitalWrite(in1Pin, HIGH);
    digitalWrite(in2Pin, LOW);
    snelheid = map(potWaarde, midden, 1023, 0, 255);
  }

  analogWrite(enablePin, snelheid);
}
Een echte machine krijgt hier nog een dode zone

Precies in het midden staat de motor stil, maar één stapje ernaast draait hij al. Een potentiometer die net op de grens blijft hangen laat de motor dan zachtjes zoemen zonder te draaien. In de praktijk maak je daar een dode zone rond: alles tussen pakweg 480 en 540 betekent stil. Dat idee kom je in de laatste oefening van dit labo opnieuw tegen, daar onder de naam hysteresis.
