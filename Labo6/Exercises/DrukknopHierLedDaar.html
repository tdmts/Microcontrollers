Een drukknop hier, een led daar

De drukknop zit op Arduino 1, de led op Arduino 2, en de enige verbinding tussen de knop en de led is de seriële lijn.

Tot nu toe stuurde je gegevens door om ze te tonen. Hier stuur je een opdracht, waarbij de ene Arduino de andere zegt wat die moet doen.

Deze oefening werk je uit in TinkerCAD. Vertrek van de bedrading uit de vorige oefening.

Het schema

Wat er bij komt bovenop de seriële verbinding
Bord Aansluiting Waarvoor
Arduino 1 pin 2 De drukknop, met INPUT_PULLUP
Arduino 2 pin 3 De led, via een weerstand van 220 Ω

De drie draden van de seriële verbinding blijven liggen waar ze liggen. Op de knop gebruik je de interne pull-up, dus je hebt geen aparte weerstand nodig. Herlees zo nodig Pull up en pull down weerstanden.

Wat je moet programmeren

  1. Arduino 1 leest de knop uit en stuurt een 1 als ze ingedrukt wordt, en een 0 als ze weer losgelaten wordt.
  2. Arduino 2 leest die lijn en schakelt de led.

Stuur je bij elke ronde van de loop() de stand van de knop door, dan gaan er duizenden boodschappen per seconde over de lijn, terwijl er hoogstens een paar keer per seconde iets verandert. Stuur dus alleen iets door wanneer de knop van stand verandert. Daarvoor moet je onthouden wat de vorige stand was.

De lijn heeft een beperkte snelheid

Bij 9600 baud passen er ongeveer 960 tekens per seconde over de draad. Een loop() draait duizenden keren per seconde. Blijf je maar zenden, dan loopt de ontvangstbuffer van 64 bytes over en gaan er boodschappen verloren, terwijl je led een halve seconde achterloopt op je vinger. Zenden bij verandering lost dat allebei op.

Dendering

Een mechanische knop maakt bij het indrukken een paar keer heel snel contact en verbreekt het weer. Zonder ontdendering stuur je dus vier of vijf boodschappen bij één druk. Een korte delay() nadat je een verandering opgemerkt hebt volstaat hier. Zie Debouncen.

Oplossing

De truc zit in vorigeStand. Die onthoudt tussen twee rondes van de loop() door wat de knop de vorige keer deed. Pas als de huidige stand daarvan verschilt, is er iets gebeurd dat de moeite is om door te sturen.

Arduino 1, met de drukknop:

const int knopPin = 2;

int vorigeStand = HIGH; // niet ingedrukt, door de pull-up

void setup()
{
  pinMode(knopPin, INPUT_PULLUP);

  Serial.begin(9600);
}

void loop()
{
  int stand = digitalRead(knopPin);

  if (stand != vorigeStand)
  {
    if (stand == LOW) // ingedrukt
    {
      Serial.println(1);
    }
    else
    {
      Serial.println(0);
    }

    vorigeStand = stand;

    delay(50); // laat de dendering uitsterven
  }
}

Arduino 2, met de led:

const int ledPin = 3;

void setup()
{
  pinMode(ledPin, OUTPUT);

  Serial.begin(9600);
}

void loop()
{
  if (Serial.available() > 0)
  {
    String regel = Serial.readStringUntil('\n');
    regel.trim();

    if (regel == "1")
    {
      digitalWrite(ledPin, HIGH);
    }
    else if (regel == "0")
    {
      digitalWrite(ledPin, LOW);
    }
  }
}

Merk op dat het programma van Arduino 2 bijna letterlijk dat van de eerste oefening is. Voor de ontvanger maakt het niets uit of die 1 door jou getypt is of door een andere Arduino gestuurd.
