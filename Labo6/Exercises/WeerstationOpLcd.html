Weerstation op het LCD

Dezelfde drie boodschappen als in de vorige oefening, maar nu verschijnen ze op een LCD in plaats van in de seriële monitor. Bovenaan staat waarover het gaat, onderaan de waarde.

Je hebt nu alles wat je nodig hebt. Het uitpluizen van de boodschappen ken je uit de vorige oefening, en het LCD ken je uit Tekst op een I²C LCD display. Wat overblijft is de twee samenbrengen, en nadenken over wat er op zo'n schermpje van twee regels past.

Deze oefening werk je uit in TinkerCAD.

Zet het type en het adres goed

Selecteer het LCD in TinkerCAD en zet Type op PCF8574-based met Address op 32, dat is 0x20. In je sketch gebruik je de bibliotheek LiquidCrystal_I2C, niet Adafruit_LiquidCrystal. Dit staat allemaal uitgelegd op de pagina van labo 4.

Elke keer dat er een nieuwe boodschap binnenkomt, vervang je wat er op het scherm staat.

Een LCD wist zichzelf niet

Schrijf je Rel. vochtigheid over Windrichting heen, dan blijven de letters die uitsteken gewoon staan en lees je iets als Rel. vochtighed. Roep dus lcd.clear() aan voor je nieuwe tekst zet, of vul je regels aan met spaties tot precies 16 tekens.

Reken trouwens even na: Rel. vochtigheid is exact 16 tekens lang. Meer past er niet op een regel.

Oplossing

Het uitpluizen van de lijn is woord voor woord hetzelfde als in de vorige oefening. Alleen wat er met het resultaat gebeurt, is anders. Daarom staat het tonen in een aparte functie toon(): die krijgt een titel en een waarde, en zet die op de twee regels. Zo staat de lcd.clear() op één plaats in plaats van drie keer, en kan je hem dus ook maar één keer vergeten.

Arduino 1 is de zender uit de vorige oefening, ongewijzigd.

Arduino 2, met het LCD:

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const int adresLcd = 0x20;
const int aantalKolommen = 16;
const int aantalRijen = 2;

LiquidCrystal_I2C lcd(adresLcd, aantalKolommen, aantalRijen);

void setup()
{
  Serial.begin(9600);

  lcd.init();
  lcd.backlight();

  lcd.setCursor(0, 0);
  lcd.print("Weerstation");
  lcd.setCursor(0, 1);
  lcd.print("Wachten...");
}

void toon(String titel, String waarde)
{
  lcd.clear(); // anders blijven letters van de vorige boodschap staan

  lcd.setCursor(0, 0);
  lcd.print(titel);

  lcd.setCursor(0, 1);
  lcd.print(waarde);
}

void loop()
{
  if (Serial.available() > 0)
  {
    String regel = Serial.readStringUntil('\n');
    regel.trim();

    int scheiding = regel.indexOf(':');

    if (scheiding > 0)
    {
      String sleutel = regel.substring(0, scheiding);
      String waarde = regel.substring(scheiding + 1);

      if (sleutel == "TEMP")
      {
        toon("Temperatuur", waarde + " C");
      }
      else if (sleutel == "WIND")
      {
        toon("Windrichting", waarde + " graden");
      }
      else if (sleutel == "HUMIDITY")
      {
        toon("Rel. vochtigheid", waarde + " %");
      }
      else
      {
        toon("Onbekend", sleutel);
      }
    }
  }
}

Merk op dat de waarde hier nooit omgezet wordt naar een getal. Dat hoeft ook niet: op een scherm zet je tekst, en de zender heeft er al tekst van gemaakt. waarde + " C" plakt gewoon de eenheid erachter. Zou je iets met die waarde moeten rekenen, bijvoorbeeld een alarm bij meer dan 30 graden, dan heb je toFloat() wél nodig.
