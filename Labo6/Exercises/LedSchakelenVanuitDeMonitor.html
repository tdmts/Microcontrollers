Led schakelen vanuit de seriële monitor

Typ een 1 in de seriële monitor en de led gaat aan. Typ een 0 en ze gaat weer uit. Voor het eerst stuur jij iets náár de Arduino in plaats van omgekeerd.

Sinds labo 0 gebruik je Serial.println() om te zien wat je programma doet. Dat verkeer ging altijd maar één kant op. Het seriële kanaal werkt echter in twee richtingen, en in dit labo ga je die tweede richting gebruiken. Lees eerst Boodschappen lezen, daar staat het gereedschap dat je nodig hebt.

Deze oefening werk je uit in TinkerCAD. Je hebt maar één Arduino nodig.

Wat je moet programmeren

Lees in je loop() een volledige lijn uit de seriële monitor met Serial.readStringUntil('\n') en vergelijk ze met "1" en "0". Bij een 1 gaat de led aan, bij een 0 uit.

Stuur bij elke opdracht ook een bevestiging terug, zodat je in de monitor ziet dat je boodschap aangekomen is. En bedenk wat er moet gebeuren als iemand iets anders typt dan een 1 of een 0: laat je programma dat gewoon zeggen in plaats van het te negeren.

Vergeet de trim() niet

Wat je typt komt binnen met een regeleinde erachter. Zonder regel.trim() vergelijk je dus "1\r" met "1", en dat is niet gelijk. Je programma lijkt dan gewoon niet te werken, zonder ook maar één foutmelding.

Een klein moment geduld is normaal

Stuurt de monitor geen regeleinde mee, dan wacht readStringUntil() nog even af of er nog iets komt. Standaard is dat één seconde. Daarna krijg je je tekst gewoon binnen. Zie je dus een korte vertraging tussen je Enter en de led, dan is dat dit en niet een fout in je programma. Met Serial.setTimeout(100) in je setup() maak je dat wachten korter.

Oplossing

De if (Serial.available() > 0) houdt de rest tegen zolang er niets binnengekomen is. Zonder die regel zou je programma bij elke ronde van de loop() proberen te lezen en telkens een seconde blijven wachten.

De else onderaan is geen versiering. Een programma dat zwijgt als het je niet begrijpt, laat je zoeken naar een fout die er niet is.

const int ledPin = 3;

void setup()
{
  pinMode(ledPin, OUTPUT);

  Serial.begin(9600);
  Serial.println("Typ 1 om de LED aan te zetten, 0 om ze uit te zetten.");
}

void loop()
{
  if (Serial.available() > 0)
  {
    String regel = Serial.readStringUntil('\n');
    regel.trim();

    if (regel == "1")
    {
      digitalWrite(ledPin, HIGH);
      Serial.println("LED aan");
    }
    else if (regel == "0")
    {
      digitalWrite(ledPin, LOW);
      Serial.println("LED uit");
    }
    else
    {
      Serial.print("Ik versta '");
      Serial.print(regel);
      Serial.println("' niet. Typ 1 of 0.");
    }
  }
}
