Bibliotheken gebruiken

Eén van de sterke punten van de Arduino-omgeving is het grote aanbod aan softwarebibliotheken. Grote stukken ingewikkelde code zitten verpakt in een bibliotheek, zodat jij alleen nog de functies hoeft te kennen die ze aanbiedt.

We bekijken als voorbeeld de Wire-bibliotheek, waarmee je I²C-elektronica kan aansturen.

Een bibliotheek toevoegen

Om een bibliotheek te gebruiken moet ze eerst toegevoegd zijn aan de Arduino-omgeving. Wire is standaard al geïnstalleerd, dus die hoef je niet apart te installeren. Andere bibliotheken voeg je het gemakkelijkst toe via de optie Bibliotheken beheren, te vinden via het menu Schets > Bibliotheek gebruiken. Via datzelfde menu kies je daarna de bibliotheek die je wil gebruiken.

Bovenaan je programma verschijnt dan een regel:

#include <naamVanDeBibliotheek.h>

In het geval van de Wire-bibliotheek wordt dat:

#include <Wire.h>

Uitzoeken welke functies er zijn

Welke functies een bibliotheek allemaal aanbiedt, vind je terug via de officiële Arduino-site. Via Software > Reference kom je op het overzicht van alle instructies. Onderaan die pagina staat een link naar de libraries-pagina, met een overzicht van de meeste bibliotheken. Kies je daar Wire, dan kom je op de specifieke pagina van die bibliotheek terecht en zie je rechts een lijst van de beschikbare functies.

Bibliotheekfuncties gebruiken

Door de #include-instructie zijn al die functies beschikbaar in je eigen programma. Voor het aansturen van een PCF8574 volstaat het bijvoorbeeld om in de setup een Wire.begin() op te nemen:

void setup()
{
  Wire.begin();
}

En in de loop-functie de combinatie:

void loop()
{
  Wire.beginTransmission(adres);
  Wire.write(waarde);
  Wire.endTransmission();
}

Elk van die functies moet de nodige parameters meekrijgen:

  • beginTransmission() krijgt het adres mee van de chip waar je naartoe wil schrijven.
  • write() krijgt de waarde mee die geschreven moet worden.
  • endTransmission() zorgt ervoor dat de I²C-communicatie opgestart en uitgevoerd wordt.
Let op de hoofdletters

De functie heet Wire.write() met een kleine w. Wire.Write() bestaat niet en levert je een compileerfout op. Datzelfde geldt voor Wire.read() en Wire.available().

Voorbeeldprogramma's

Elke goede bibliotheek (ja, er zijn er ook slechte) bevat een aantal voorbeeldprogramma's. Die kunnen vaak als leidraad dienen om te zien hoe je de functies het best implementeert. Je vindt ze terug via Bestand > Voorbeelden > naam van de bibliotheek.
