Het I²C adres vinden

Onderstaand programma, de I2C scanner, loopt alle adressen van de bus af om te kijken welke chips er aanwezig zijn. Het adres van elke gevonden chip verschijnt in de seriële monitor.

Zet je seriële monitor eerst op 115200 baud

Open eerst de seriële monitor en pas de snelheid aan zoals ze in de code staat. Doe je dat niet, dan krijg je alleen onleesbare tekens te zien en kan de Arduino IDE vastlopen.

De scanner

#include <Wire.h>

void setup()
{
  Wire.begin();

  Serial.begin(115200);
  while (!Serial); // op een Leonardo: wacht tot de seriële monitor open is

  Serial.println("\nI2C scanner");
}

void loop()
{
  int aantalGevonden = 0;

  Serial.println("Scannen...");

  // Adres 0 en 127 zijn gereserveerd, die slaan we over
  for (byte adres = 1; adres < 127; adres++)
  {
    // De scanner gebruikt de returnwaarde van endTransmission() om te zien
    // of er op dit adres een chip antwoordt
    Wire.beginTransmission(adres);
    byte fout = Wire.endTransmission();

    if (fout == 0)
    {
      Serial.print("I2C-toestel gevonden op adres 0x");
      if (adres < 16)
      {
        Serial.print("0");
      }
      Serial.println(adres, HEX);

      aantalGevonden++;
    }
    else if (fout == 4)
    {
      Serial.print("Onbekende fout op adres 0x");
      if (adres < 16)
      {
        Serial.print("0");
      }
      Serial.println(adres, HEX);
    }
  }

  if (aantalGevonden == 0)
  {
    Serial.println("Geen I2C-toestellen gevonden");
  }
  else
  {
    Serial.println("Klaar");
  }

  delay(5000); // wacht 5 seconden op de volgende scan
}

Hoe werkt dat?

De scanner doet voor elk adres alsof hij iets gaat versturen, maar stuurt niets mee. Wire.endTransmission() geeft een getal terug dat vertelt hoe dat afgelopen is. Antwoordt er een chip op dat adres, dan is die returnwaarde 0. Antwoordt er niets, dan krijg je een andere waarde en weet je dat daar niets hangt.

Deze sketch test de standaard 7-bit adressen. Toestellen met een langer adres worden mogelijk niet correct herkend.

Vind je niets?

Controleer dan eerst je bedrading. De meest voorkomende oorzaken zijn een vergeten GND-verbinding tussen Arduino en breadboard, SDA en SCL die omgewisseld staan, of adreslijnen A0 tot A2 die nergens aan vasthangen. Zie ook Werken met de PCF8574.
