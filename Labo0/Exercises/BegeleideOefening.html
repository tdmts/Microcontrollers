Begeleide oefening

In deze oefening bouw je stap voor stap een schakeling met een drukknop en een led. We beginnen heel klein en breiden je programma telkens een beetje uit, tot je op het einde een led laat knipperen met een functie die je zelf hebt geschreven. Neem rustig de tijd en lees bij elke stap ook even het waarom.

Stappenplan

Stap 1: Sketch aanmaken

Open de Arduino IDE en verbind je Arduino met een USB-kabel met je computer. De Arduino krijgt zo meteen ook stroom, je hoeft dus verder niets aan te sluiten.

Controleer nu of je computer je Arduino herkent. Bovenaan in de IDE kies je bij Select board je bord en de juiste poort. Lukt dat niet meteen? In Een programma uploaden lees je hoe je het juiste bord en de juiste poort selecteert.

Maak daarna een nieuwe sketch en sla hem op onder de naam Labo0_KnopEnLed. Zo vind je je werk straks makkelijk terug.

Stap 2: Drukknop aansluiten op pin 2

Verbind een pushbutton met pin 2 van je Arduino. Werk altijd op een uitgeschakelde of losgekoppelde Arduino terwijl je bedraadt, zo vermijd je kortsluitingen.

Een knopingang mag niet "zweven": zonder vaste waarde leest de pin willekeurig hoog of laag. Daarom plaats je tussen pin 2 en de +5 V een pull-upweerstand, die de ingang een vaste rustwaarde geeft. Neem daarvoor best een weerstand van ongeveer 10 kΩ (een waarde tussen 1 kΩ en 10 kΩ werkt). Sluit alles aan zoals op de foto:

Pas nu je programma aan. Maak bovenaan een constante knopPin met de waarde 2. Door met een naam te werken in plaats van het getal 2 blijft je code leesbaar en pas je het pinnummer later op één plaats aan. Omdat je zelf een externe pull-upweerstand plaatst, stel je de pin in setup() in als gewone ingang met pinMode(knopPin, INPUT).

const int knopPin = 2;

void setup()
{
  pinMode(knopPin, INPUT);
}

void loop()
{

}

Elke Arduino-sketch bevat altijd deze twee functies. setup() wordt één keer uitgevoerd bij het opstarten en gebruik je om alles klaar te zetten, zoals hier je pinMode. loop() wordt daarna continu herhaald en bevat de eigenlijke werking van je programma. Ze moeten allebei aanwezig zijn, ook als er (zoals nu) nog niets in loop() staat.

Wil je liever geen externe weerstand plaatsen? Dan kan je in plaats daarvan de ingebouwde pull-up van de Arduino gebruiken met INPUT_PULLUP. Je hoeft de weerstand op de foto dan niet te plaatsen, en verder blijft alles gelijk.

Stap 3: Denk eens na over de niveaus bij een pull-up

Voor je iets uittest: probeer eerst zelf te redeneren. Als je een pull-up-weerstand gebruikt, welk niveau (hoog of laag) verwacht je op de pin wanneer je de knop niet indrukt? En welk niveau wanneer je de knop wel indrukt?

Bij een pull-up trekt de weerstand de pin standaard naar 5 V, dus je leest HIGH (1) zolang je de knop niet indrukt. Druk je de knop in, dan verbind je de pin met de massa (GND) en lees je LOW (0). De logica is dus omgekeerd aan wat je intuïtief zou verwachten: ingedrukt = 0.

Stap 4: Je redenering testen via de Seriële monitor

Nu ga je controleren of je redenering klopt. Schrijf een kort debug-programma dat de status van de knop met digitalRead uitleest en naar de Seriële monitor stuurt. Laad het daarna op met de knop Upload (zie Een programma uploaden als je twijfelt).

Open vervolgens de Seriële monitor en druk de knop enkele keren in. De waarde die je ziet (1 = hoog, 0 = laag) zou moeten overeenkomen met wat je in stap 3 had voorspeld. Komt het overeen? Dan snap je de pull-up. Zo niet, controleer dan rustig je bedrading en je pinMode.

const int knopPin = 2;

void setup()
{
  pinMode(knopPin, INPUT);
  Serial.begin(9600);
}

void loop()
{
  int toestand = digitalRead(knopPin);
  Serial.print("Status: ");
  Serial.println(toestand);
}
Tip: instellingen van de Seriële monitor

Zet rechtsonder in de Seriële monitor de snelheid op 9600 baud, gelijk aan de waarde in Serial.begin(9600). Staat die anders, dan zie je onleesbare tekens. Zet er daarnaast het regeleinde op New line, omdat je in de code Serial.println gebruikt: zo komt elke status op een eigen regel.

Stap 5: led aansluiten op pin 3

Verbind een led met pin 3 en sluit hem aan volgens het principe van sourcing: de pin levert de stroom die door de led loopt. Plaats een voorschakelweerstand van 220 Ω in serie met de led om die stroom te begrenzen. Hoe je precies aan die 220 Ω komt, reken je zelf uit in stap 7.

Let goed op de polariteit van je led. Met het ezelsbruggetje KNAP onthoud je het makkelijk: Kathode Negatief, Anode Positief. Je herkent de kathode (de minkant) op twee manieren:

De behuizing is vlak aan de kant van de kathode en rond aan de kant van de anode. Het "vlakje" binnen in de led is groter bij de kathode dan bij de anode.

Stap 6: Denk eens na over de niveaus voor sourcing

Opnieuw eerst zelf redeneren. Als je de led aanstuurt volgens sourcing, welk niveau moet er dan op de anode staan en welk op de kathode om de led te doen oplichten?

Bij sourcing komt de anode (de pluskant) aan de pin. Zet je de pin HIGH, dan staat de anode op ongeveer 5 V en de kathode via de weerstand op 0 V (GND). Er loopt dan stroom van de anode naar de kathode en de led brandt. Zet je de pin LOW, dan is er geen spanningsverschil en blijft de led uit.

Stap 7: De juiste voorschakelweerstand berekenen

Nu berekenen we welke weerstand je nodig hebt. In de datasheet van een led vind je twee waarden terug. De Iforward is de nominale stroom die je door de led wil sturen om die mooi te laten branden, vaak ongeveer 20 mA. De Vforward is de spanning die over de led staat bij die stroom, meestal tussen 1,8 V en 2 V.

Met de wet van Ohm reken je de weerstand uit. Je trekt eerst de spanning over de led af van de voedingsspanning, want dat is het stuk spanning dat de weerstand moet opnemen:

$$ R = \frac{U}{I} = \frac{V_{CC} - V_{forward}}{I_{forward}} = \frac{5\,\text{V} - 1{,}8\,\text{V}}{20\,\text{mA}} \approx 160\ \Omega \text{ (theoretisch)} $$

Stap 8: Denk eens na over de beschikbare weerstandswaarden

Je berekende 160 Ω, maar dat is een theoretische waarde. Zit die 160 Ω ook echt in je Arduino-starterkit? En welke weerstand neem je dan best?

160 Ω is een standaardwaarde uit de E24-reeks (de reeks van de gangbare 5%-weerstanden), maar in een basis-starterkit zit die waarde meestal niet. Je neemt dan de dichtstbijzijnde hogere waarde die je wél hebt: 220 Ω. Rond bij twijfel altijd naar boven af: een iets grotere weerstand betekent iets minder stroom en dus een iets minder felle, maar veiligere led.

Stap 9: Denk eens na over de stroom die een pin levert

Nog een denkoefening. Hoeveel stroom kan een pin van de Arduino eigenlijk leveren? En hebben we die voorschakelweerstand dan wel echt nodig?

Een pin van de Arduino Uno levert veilig ongeveer 20 mA. Het absolute maximum is 40 mA (de schadegrens), en alle pinnen samen mogen niet boven ongeveer 200 mA komen. Een led brandt mooi rond die 20 mA, dus qua led zit je goed.

Sluit je de led echter zonder weerstand aan, dan legt niets de stroom vast behalve de led zelf en de kleine inwendige weerstand van de pin (grofweg 25 Ω). De stroom is dan geen nette 40 mA, maar loopt ongecontroleerd op tot ruim boven de aanbevolen 20 mA en voorbij het absolute maximum van 40 mA. Dat overbelast de pin en kan zowel de pin als de led beschadigen. Net daarom heb je de weerstand nodig: die legt de stroom vast op een gekende, veilige waarde. Meer hierover lees je bij Sourcen en sinken.

Ben je nieuwsgierig? Bouw dit gerust zelf na in TinkerCAD en meet de stroom met een multimeter die je op Stroomsterkte zet. Je ziet dan een stroom van ongeveer 53 mA verschijnen, ruim boven de veilige grens.

Stap 10: De led laten reageren op de knop

Nu koppelen we knop en led aan elkaar. Breid je programma uit met een digitalWrite zodat de led aangaat wanneer je de knop indrukt en weer uitgaat wanneer je loslaat. Denk terug aan stap 3: bij een pull-up is de knop ingedrukt wanneer je LOW leest, dus daar test je met een tweevoudige selectie (if / else) op.

const int knopPin = 2;
const int ledPin = 3;  // ledPin definiëren

void setup()
{
  pinMode(knopPin, INPUT);
  pinMode(ledPin, OUTPUT); // ledPin is een OUTPUT
  Serial.begin(9600);
}

void loop()
{
  int toestand = digitalRead(knopPin);
  Serial.print("Status: ");
  Serial.println(toestand);

  if (toestand == LOW)
  {
    // pull up -> LOW = er werd op de knop gedrukt
    digitalWrite(ledPin, HIGH); // Sourcing -> HIGH = de LED brandt
  }
  else
  {
    digitalWrite(ledPin, LOW); // Sourcing -> LOW = de LED brandt niet
  }
}

Stap 11: Debouncing toevoegen

Een mechanische knop dendert kort bij het indrukken: de contacten maken en verbreken de verbinding een paar keer heel snel na elkaar voor ze stabiel blijven, waardoor de Arduino snel na elkaar meerdere drukken kan zien. Dat heet contactdender. Je lost het hier eenvoudig op met een korte debouncing: zodra je gedetecteerd hebt dat de knop ingedrukt is, wacht je even tot het denderen voorbij is. Zet de delay dus binnen de if, na wat je bij een druk wil doen.

const int knopPin = 2;
const int ledPin = 3;  // ledPin definiëren

void setup()
{
  pinMode(knopPin, INPUT);
  pinMode(ledPin, OUTPUT); // ledPin is een OUTPUT
  Serial.begin(9600);
}

void loop()
{
  int toestand = digitalRead(knopPin);
  Serial.print("Status: ");
  Serial.println(toestand);

  if (toestand == LOW)
  {
    // pull up -> LOW = er werd op de knop gedrukt
    digitalWrite(ledPin, HIGH); // Sourcing -> HIGH = de LED brandt
    delay(50); // debouncing: wacht tot het denderen voorbij is
  }
  else
  {
    digitalWrite(ledPin, LOW); // Sourcing -> LOW = de LED brandt niet
  }
}

Stap 12: Een eigen knipper()-functie maken

Vanaf hier maken we je code netter met een eigen functie. Schrijf een functie knipper() die de led 3 keer na elkaar aan- en uitzet wanneer je de knop indrukt. Vergeet niet om de functie ook echt op te roepen in je loop().

const int knopPin = 2;
const int ledPin = 3;  // ledPin definiëren

void setup()
{
  pinMode(knopPin, INPUT);
  pinMode(ledPin, OUTPUT); // ledPin is een OUTPUT
  Serial.begin(9600);
}

void loop()
{
  int toestand = digitalRead(knopPin);
  Serial.print("Status: ");
  Serial.println(toestand);

  if (toestand == LOW)
  {
    // pull up -> LOW = er werd op de knop gedrukt
    knipper(); // verwijs naar de functie knipper
    delay(50); // debouncing: wacht tot het denderen voorbij is
  }
  else
  {
    digitalWrite(ledPin, LOW); // Sourcing -> LOW = de LED brandt niet
  }
}

void knipper()
{
  digitalWrite(ledPin, HIGH); // Sourcing -> HIGH = de LED brandt
  delay(50);
  digitalWrite(ledPin, LOW); // Sourcing -> LOW = de LED brandt niet
  delay(50);

  digitalWrite(ledPin, HIGH); // Sourcing -> HIGH = de LED brandt
  delay(50);
  digitalWrite(ledPin, LOW); // Sourcing -> LOW = de LED brandt niet
  delay(50);

  digitalWrite(ledPin, HIGH); // Sourcing -> HIGH = de LED brandt
  delay(50);
  digitalWrite(ledPin, LOW); // Sourcing -> LOW = de LED brandt niet
  delay(50);
}

Stap 13: knipper() vereenvoudigen met een iteratie

Je hebt dezelfde regels nu drie keer gekopieerd, en dat kan korter. Vervang de herhaling door een for-lus, die het blok automatisch drie keer uitvoert. Kortere code die hetzelfde doet, is makkelijker te lezen en aan te passen.

const int knopPin = 2;
const int ledPin = 3;  // ledPin definiëren

void setup()
{
  pinMode(knopPin, INPUT);
  pinMode(ledPin, OUTPUT); // ledPin is een OUTPUT
  Serial.begin(9600);
}

void loop()
{
  int toestand = digitalRead(knopPin);
  Serial.print("Status: ");
  Serial.println(toestand);

  if (toestand == LOW)
  {
    // pull up -> LOW = er werd op de knop gedrukt
    knipper(); // verwijs naar de functie knipper
    delay(50); // debouncing: wacht tot het denderen voorbij is
  }
  else
  {
    digitalWrite(ledPin, LOW); // Sourcing -> LOW = de LED brandt niet
  }
}

void knipper()
{
  for (int i = 1; i <= 3; i++)
  {
    digitalWrite(ledPin, HIGH); // Sourcing -> HIGH = de LED brandt
    delay(50);
    digitalWrite(ledPin, LOW); // Sourcing -> LOW = de LED brandt niet
    delay(50);
  }
}

Stap 15: Ook de duurtijd instelbaar maken

Als laatste stap maak je ook de snelheid instelbaar. Voeg een tweede parameter duurtijd toe die bepaalt hoe lang de led telkens aan en uit staat. Roep de functie zo op dat de led 4 keer knippert met een duurtijd van 100 ms: knipper(4, 100). Je hebt daarmee een herbruikbare functie waarin je zelf het aantal en het tempo bepaalt.
