Hard-en software

Een overzicht van wat je nodig hebt voor dit vak: welke hardware je aanschaft, en welke software je installeert om je Arduino te programmeren.

Hardware

  • Arduino starterkit (Velleman kit) via Depraets
  • Tijdens de verplichte lessen worden ook extra componenten zoals schuifregisters, transistoren, motoren, ... uitgedeeld

Software

  • Download de Arduino Integrated Development Environment (IDE) via Academic Software of https://www.arduino.cc
    • Bij installatie zet je alle opties aan, extra drivers installeer je
  • Registreer je op TinkerCAD met je HOGENT e-mail adres
    • TinkerCAD is een simulatie omgeving die we gaan gebruiken als we oefeningen maken met componenten die jullie niet ter beschikking hebben
