Functies en parameters

Een functie is een stukje code dat een bepaalde taak uitvoert. Het voordeel is dat je die taak kunt hergebruiken zonder telkens opnieuw dezelfde code te schrijven.

Elk Arduino-programma heeft standaard twee functies:

  • setup(): dit wordt één keer uitgevoerd wanneer de Arduino opstart. Hier zet je meestal de begininstellingen (bv. pinnummers instellen).
  • loop(): dit wordt telkens opnieuw herhaald zolang de Arduino aanstaat. Hier zet je de code die continu moet draaien.

Eigen functies maken

Je kan ook zelf functies maken. Bijvoorbeeld:

const int pinLed = 2;

void setup()
{
  pinMode(pinLed, OUTPUT);
}

void loop()
{
  blinkLed(200);   // laat de LED 200 ms branden
  blinkLed(1000);  // laat de LED 1000 ms branden
}

// functie met parameter
void blinkLed(int tijd)
{
  digitalWrite(pinLed, HIGH);  // LED aan
  delay(tijd);                 // wacht de opgegeven tijd
  digitalWrite(pinLed, LOW);   // LED uit
  delay(tijd);                 // wacht de opgegeven tijd
}

Uitleg

  • De functie heet blinkLed.
  • Tussen de haakjes staat int tijd, dat is de parameter.
  • Wanneer we de functie aanroepen (blinkLed(200) of blinkLed(1000)), vullen we die parameter in met een waarde.
  • Binnen de functie wordt die waarde gebruikt door delay(tijd).

Zo kan je dezelfde functie gebruiken voor verschillende situaties, zonder dat je code moet kopiëren of herschrijven.
