Selecties

Een keuze maken in je programma doe je op basis van een voorwaarde. Die voorwaarde stel je op als een vergelijking (is gelijk aan, is groter dan, ...) en die vergelijking moet altijd te herleiden zijn tot true of false.

De instructie digitalRead(pinNummer) leest de status in van een pin. Die kan 1 (= HIGH) of 0 (= LOW) zijn.

Waarop test je bij een knop?

De voorbeelden hieronder testen op HIGH, wat past bij een knop met een pull-downweerstand. Werk je met een pull-up of met INPUT_PULLUP, dan is een ingedrukte knop juist LOW en test je dus op LOW. Zie Pull up en pull down weerstanden. De selectiestructuur zelf blijft in beide gevallen dezelfde.

Voorbeeld enkelvoudige selectie

const int pinButton = 3;

void setup()
{
  pinMode(pinButton, INPUT);
}

void loop()
{
  int value = digitalRead(pinButton);
  if(value == HIGH) // de voorwaarde is te herleiden tot true / false
  {
    // doe iets als de voorwaarde true is
  }
}

Voorbeeld tweevoudige selectie

const int pinButton = 3;

void setup()
{
  pinMode(pinButton, INPUT);
}

void loop()
{
  int value = digitalRead(pinButton);
  if(value == HIGH) // de voorwaarde is te herleiden tot true / false
  {
    // doe iets als de voorwaarde true is
  }
  else
  {
    // doe iets anders als de voorwaarde false is
  }
}

Een tweevoudige selectie in het kort

Kies je met een if/else tussen twee waarden, en verder niets, dan mag dat ook in één regel. Daarvoor bestaat de operator ?:. Je schrijft eerst de voorwaarde, dan een vraagteken, dan de waarde als de voorwaarde waar is, dan een dubbele punt, en tot slot de waarde als ze niet waar is:

voorwaarde ? waardeAlsWaar : waardeAlsNietWaar

Deze twee stukken code doen exact hetzelfde:

// De volledige schrijfwijze
if (value == HIGH)
{
  digitalWrite(pinLed, HIGH);
}
else
{
  digitalWrite(pinLed, LOW);
}

// Dezelfde keuze, in het kort
digitalWrite(pinLed, value == HIGH ? HIGH : LOW);

Het verschil met een gewone if is dat ?: zelf een waarde oplevert. Je kan hem daarom rechtstreeks meegeven als argument van een functie, zoals hierboven, of in een toekenning zetten:

int helderheid = knopIngedrukt ? 255 : 0;

Wat analogRead() teruggeeft

De instructie analogRead(pinNummer) leest de analoge status (= de spanning) in van een pin. Dit kan een waarde tussen 0 en 1023 zijn waarbij 0 overeenkomt met 0 V en 1023 overeenkomt met 5 V.

Voorbeeld meervoudige selectie met logische operatoren

const int pinButton = 3;
const int pinSensor = A0;

void setup()
{
  pinMode(pinButton, INPUT);
  pinMode(pinSensor, INPUT);
}

void loop()
{
  int value = analogRead(pinSensor);
  int status = digitalRead(pinButton);

  if(value > 768 && status == HIGH)
  {

  }
  else if (value > 512 || status == LOW)
  {

  }
  else
  {

  }
}
