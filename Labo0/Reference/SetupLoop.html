Setup en loop

Een Arduino-programma MOET altijd bestaan uit twee functies: setup en loop.

void setup() {
  // Hier komt code die maar één keer wordt uitgevoerd, bij de opstart van de Arduino
}

void loop() {
  // Hier komt code die steeds opnieuw wordt uitgevoerd, na het uitvoeren van setup
}

setup()

  • Wordt één keer uitgevoerd, direct nadat de Arduino wordt aangezet of gereset.
  • Gebruik je om de startinstellingen te maken.
  • Typische voorbeelden:
    • Pinnen instellen als input (invoer, bv. een knop) of output (uitvoer, bv. een led).
    • Starten van communicatie.

loop()

  • Wordt direct na setup() uitgevoerd.
  • Wordt steeds opnieuw uitgevoerd, in een eindeloze lus.
  • Hier schrijf je de code die je Arduino continu moet herhalen.
  • Typische voorbeelden:
    • Een led aan- en uitzetten.
    • Lezen van een sensorwaarde.
    • Reageren op een drukknop.
