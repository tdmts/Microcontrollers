Iteraties

Naast de sequentie en de selectie is de iteratie één van de drie basisstructuren waarmee een programma wordt opgebouwd. Itereren betekent letterlijk herhalen. Het is dus een structuur om een stuk code een aantal keer te herhalen. Dit kan een oneindige herhaling zijn zoals de loop()-functie, maar kan ook een conditionele herhaling zijn zoals een for-lus of een while-constructie.

De for-instructie

Bij de for-instructie gaat het om een lus waarvan je op voorhand weet hoeveel keer hij moet doorlopen worden. Dit aantal keer kan ook een variabele waarde zijn, maar het gaat erom dat het zeker is dat na x aantal keer de lus te hebben doorlopen het programma verder gezet wordt.

Syntax

for (initialisatie; voorwaarde; aanpassing)
{
    // instructies
}

Parameters

  • initialisatie: gebeurt eerst en eenmalig. Hier wordt een variabele op een waarde geïnitialiseerd. Deze variabele gaat via de voorwaarde bepalen of de lus nog verder doorlopen wordt of beëindigd wordt. Typisch gebruik je hiervoor een tellervariabele die je in de initialisatie zelf definieert.
  • voorwaarde: een uitdrukking die resulteert in een booleaanse waarde true of false. Indien de voorwaarde true is, zal de code binnen de lus opnieuw doorlopen worden. Bij een false wordt de lus stopgezet en ga je verder met de eerste instructie na de lusconstructie.
  • aanpassing: na elke doorloop van de lus wordt deze instructie uitgevoerd. In de eenvoudigste vorm wordt hier een teller, die gedefinieerd werd bij de initialisatie, met een waarde verhoogd of verlaagd, waardoor deze variabele een nieuwe waarde krijgt. Deze wordt dan afgetoetst met de voorwaarde om te bepalen of de lus nog verder moet doorlopen worden.

Voorbeeld

for (int i = 0; i < 10; i++)
{
    Serial.println(i);
}

In bovenstaand voorbeeld wordt een variabele i van het type integer op 0 geïnitialiseerd. Daarna wordt de voorwaarde een eerste maal geëvalueerd, waarbij het resultaat true is, want 0 < 10 resulteert in true. De luscode wordt een eerste keer doorlopen en via het serieel kanaal zie je 0 op de terminal verschijnen.

Na het uitvoeren van de luscode wordt de aanpassing uitgevoerd, en krijgt i de nieuwe waarde 1 door de verhoging ten gevolge van i++.

De voorwaarde wordt opnieuw geëvalueerd, waardoor er opnieuw een true als resultaat gevonden wordt: 1 < 10 is immers waar. De luscode wordt dus een tweede maal doorlopen en op de terminal verschijnt een 1.

Opnieuw wordt i met één verhoogd, waardoor i gelijk wordt aan twee. Je kan deze redenering verderzetten en zal zien dat op de terminal achtereenvolgens nog de 2, 3, 4, 5, 6, 7, 8 en 9 verschijnen.

Bij i = 9 zal de aanpassing ervoor zorgen dat i nu de waarde 10 krijgt. De voorwaarde 10 < 10 geeft nu als resultaat false, waardoor de lus niet meer uitgevoerd wordt en het programma verder gaat met de eerste instructie na de lus.

Een byte loopt maar tot 255

Bekijk dit programma:

void setup()
{
  Serial.begin(9600);
}
void loop()
{
  for (byte i = 250; i < 260; i++)
  {
    Serial.println(i);
  }
}

Op het eerste zicht zou je denken dat de lus 10 keer doorlopen wordt, met de waarden voor i die variëren van 250 tot en met 259, maar in de praktijk is dit niet waar.

Doordat i als byte gedefinieerd wordt, loopt zijn bereik slechts tot en met 255. Daarna krijg je een overflow en wordt i gelijk aan 0. De waarde 260 wordt dus nooit bereikt, met als gevolg dat deze lus oneindig gaat blijven doorlopen.

Hierboven heb je de standaardwerking van de for-lus bekeken, maar er zijn nog heel veel andere mogelijkheden. Stel dat je de eerste 10 machten van 2 wil afprinten op de terminal, dan kan dit op verschillende manieren aangepakt worden. Je kan een variabele gebruiken om de waarde elke keer te verdubbelen. De code ziet er dan als volgt uit:

void setup()
{
  Serial.begin(9600);
}

void loop()
{
  int macht = 1;
  for (byte i = 0; i < 10; i++)
  {
    Serial.println(macht);
    macht = macht * 2;
  }
}

Een tweede manier is om de waarde van de macht te berekenen met behulp van een functie. In C++ bestaat daarvoor de functie pow(grondtal, exponent). Het resultaat is een float.

void setup()
{
  Serial.begin(9600);
}

void loop()
{
  for (byte i = 0; i < 10; i++)
  {
    Serial.println(pow(2, i));
  }
}

Een derde manier maakt gebruik van de lus zelf. Je laat de teller niet gewoon optellen, maar je verdubbelt hem elke keer hij door de lus geweest is.

void setup()
{
  Serial.begin(9600);
}

void loop()
{
  for (int i = 1; i < 513; i = i * 2)
  {
    Serial.println(i);
  }
}

De while-structuur

Een tweede iteratiestructuur is de while-instructie. Hier gaat het erom dat je op voorhand niet weet hoe lang de lus moet doorlopen worden. Bij de while-structuur is het zelfs helemaal niet zeker of de luscode ooit moet doorlopen worden. Alles is afhankelijk van de voorwaarde.

Syntax

while (voorwaarde)
{
    // instructies
}

Parameters

voorwaarde: expressie die in true of false resulteert.

Voorbeeld

void setup()
{
    pinMode(3, INPUT_PULLUP);
}
void loop()
{
    while (digitalRead(3))
    {
    }
}

In bovenstaand voorbeeld wordt de luscode (waar niks in staat) uitgevoerd zolang er een hoog niveau op pin 3 staat. Zodra daar een laag niveau op komt, gaat het programma verder. Zo'n constructie kan gebruikt worden als je bijvoorbeeld wil dat het programma niet start voordat er op een startknop wordt gedrukt. Deze startknop kan dan tussen GND en pin 3 geplaatst worden.

Gevaar: oneindige lus

Aangezien de luscode uitgevoerd wordt zolang de voorwaarde resulteert in true, moet je extra opletten bij het opstellen van de voorwaarde.

Bijvoorbeeld:

void setup()
{
  Serial.begin(9600);
}

void loop()
{
  bool voorwaarde = false;
  while (voorwaarde = true)
  {
    Serial.print("surprise");
  }
}

In bovenstaande code verwacht je op het eerste zicht dat de tekst "surprise" nooit op de terminal zal verschijnen. In werkelijkheid heb je een fout gemaakt bij het opstellen van de voorwaarde, omdat je een enkel =-teken gebruikt hebt i.p.v. een dubbel =-teken. Daardoor doe je hier een toekenning van true aan de variabele "voorwaarde", waardoor de uitdrukking tussen de haakjes van de while-functie resulteert in true, en de tekst dus toch verschijnt op de terminal.

Merk ook op dat je bij een while-constructie er altijd voor moet zorgen dat in de voorwaarde of in het while-codeblok een instructie zit die ervoor kan zorgen dat de voorwaarde verandert van logische toestand. Als dit niet het geval is, krijg je een oneindige lus en zit het programma vast in deze oneindige lus.

Een programma permanent stoppen

Het kan soms de bedoeling zijn om het programma permanent te stoppen. Dat lijkt onmogelijk, aangezien het programma binnen de loop()-functie draait die oneindig herhaalt.

Je kan met de while-instructie echter zorgen voor een oneindige lus waardoor de uitvoering van het programma gestopt lijkt voor de buitenwereld. Gebruik daarvoor de constructie:

while (true)
{
}

De do-while-structuur

Een variant op de while-structuur is de do-while-structuur. Hierbij komt de voorwaarde om de lus verder uit te voeren op het einde van de luscode, waardoor de luscode gegarandeerd één keer uitgevoerd wordt.

Syntax

do
{
    // instructies
} while (voorwaarde);

Parameters

voorwaarde: idem zoals bij de while-structuur.
