Constanten, variabelen en gegevenstypes

Een variabele is een plaats in het geheugen waar je een waarde bewaart. Met een gegevenstype spreek je af wat voor soort waarde erin past, en met const geef je aan dat de waarde nooit meer verandert.

const int ledPin = 2;
bool isActief = false;
double waarde = 10.5;

void setup()
{
  isActief = true;
}

void loop()
{
  String tekst = "abc";
  char c = 'a';

  waarde = waarde + 0.5;
}

In dit voorbeeld zie je hoe we in Arduino werken met constanten en variabelen.

  • Constanten (zoals const int ledPin = 2;) krijgen één vaste waarde die tijdens het programma niet meer kan veranderen.
  • Variabelen (zoals bool isActief = false; en double waarde = 10.5;) kunnen tijdens de uitvoering van het programma wél andere waarden krijgen. In setup() wordt isActief bijvoorbeeld aangepast naar true. In loop() wordt waarde telkens met 0.5 verhoogd.

Gegevenstypes

Daarnaast zijn er verschillende gegevenstypes:

Type Beschrijving
bool Kan enkel true of false zijn.
byte Een geheel getal van 0 tot en met 255.
int Een geheel getal. Op een Arduino Uno of Leonardo kan een int waarden aannemen van -32768 tot +32767.
long Een geheel getal. Op een Arduino Uno of Leonardo kan een long waarden aannemen van ongeveer -2 miljard tot +2 miljard
double Een kommagetal. Op een Arduino Uno of Leonardo is de kleinste en grootste waarde die je kan bijhouden ongeveer ±3 × 10³⁸
float Op een Arduino Uno of Leonardo hetzelfde als een double.
String Een stuk tekst. Kan letters, cijfers en speciale tekens bevatten maar je kan er niet mee rekenen.
char Eén enkel teken, bv. 'a'of '@' of '5'.

Globaal en lokaal

Er is ook een verschil tussen globale en lokale variabelen:

  • De variabelen bovenaan (ledPin, isActief, waarde) zijn globaal en kunnen overal in het programma gebruikt worden.
  • De variabelen die je in loop() schrijft (tekst, c) zijn lokaal: ze bestaan enkel binnen die functie en verdwijnen zodra de functie klaar is.
