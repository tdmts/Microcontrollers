Wiskundige operatoren

Met wiskundige operatoren kan je berekeningen uitvoeren op variabelen en constanten.

In onderstaande voorbeeldcode zie je de meest gebruikte operatoren.

Let op!

Bij de deling moet je opletten, want het resultaat hangt af van het gegevenstype dat je gebruikt in teller en noemer. Zijn teller én noemer van het type int, dan maak je de gehele deling (quotientInt). Is teller en/of noemer van het type double, dan maak je de deling met kommagetal (quotientDouble).

int a = 10;
int b = 3;
int som;
int verschil;
int product;
int quotientInt;
int rest;
double quotientDouble;
double macht;
double wortel;
void setup()
{
  som = a + b;              // optellen → 10 + 3 = 13
  verschil = a - b;         // aftrekken → 10 - 3 = 7
  product = a * b;          // vermenigvuldigen → 10 * 3 = 30
  quotientInt = a / b;      // geheel getal delen → 10 / 3 = 3
  rest = a % b;             // modulo → 10 % 3 = 1
  quotientDouble = (double) a / b;  // delen met kommagetal → 10.0 / 3 = 3.33
  macht = pow(a, b);               // macht → 10³ = 1000
  wortel = sqrt(a);                // vierkantswortel → √10 ≈ 3.16
}
