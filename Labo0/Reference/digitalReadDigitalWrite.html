digitalRead / digitalWrite

Met digitalRead() en digitalWrite() kan je de digitale ingangen en uitgangen van de Arduino bedienen:

  • digitalWrite(pin, waarde) zet een pin hoog (HIGH) of laag (LOW), bijvoorbeeld om een led aan of uit te zetten.
  • digitalRead(pin) leest de toestand van een digitale pin: die staat hoog (HIGH) of laag (LOW), bijvoorbeeld naargelang een knop ingedrukt is of niet.
Of een ingedrukte knop HIGH of LOW geeft, hangt van je bedrading af

Dat is geen eigenschap van digitalRead() zelf, maar van hoe je de knop aansluit. Bij een pull-downweerstand, zoals in het voorbeeld hieronder, lees je in rust een LOW en bij het indrukken een HIGH. Bij een pull-upweerstand of bij INPUT_PULLUP is het net omgekeerd: in rust HIGH, ingedrukt LOW. Die tweede vorm kom je in dit vak het vaakst tegen. Zie Pull up en pull down weerstanden, en let er dus altijd op waarop je test.

const int ledPin = 2;
const int knopPin = 3;

void setup()
{
  pinMode(ledPin, OUTPUT);   // LED als uitgang
  pinMode(knopPin, INPUT);   // knop als ingang, met externe pull-downweerstand
}

void loop()
{
  int knopStatus = digitalRead(knopPin); // lees de knop

  if (knopStatus == HIGH)
  {
    digitalWrite(ledPin, HIGH);  // LED aan als knop ingedrukt
  }
  else
  {
    digitalWrite(ledPin, LOW);   // LED uit als knop niet ingedrukt
  }
}
  • ledPin en knopPin zijn globale constanten, zodat het pinnummer overal hetzelfde is.
  • In setup() worden de pinnen ingesteld.
  • In loop() leest de Arduino continu de knop en schakelt de led aan of uit.
