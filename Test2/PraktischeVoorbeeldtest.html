Praktische voorbeeldtest

Dit is de opgave voor de praktische voorbeeldtest van het tweede evaluatiemoment. Zo weet je op voorhand hoe moeilijk de echte test wordt.

Tijdens het tweede evaluatiemoment is er ook een theoretische test. Die gaat over de leerinhouden van labo 3 en labo 4. Oefen daarop met de theoretische voorbeeldtest.

Opgave

Sluit 8 leds aan op een 74HC595 schuifregister, een potentiometer op je Arduino, en een drukknop op een PCF8574 I/O-expander.

Gebruik deze pinnen, en wijk hier niet van af:

  • DS van het schuifregister op pin 2
  • STCP op pin 3
  • SHCP op pin 4
  • De potentiometer op pin A0
  • De PCF8574 op de I²C-bus: SDA op A4, SCL op A5
  • De drukknop op P0 van de PCF8574

In de opgave hieronder is led 1 de led op uitgang Q0 en led 8 die op Q7.

Situatie 1: de balk

Met de potentiometer regel je hoeveel leds er branden. De leds lopen vol vanaf led 1, dus ze branden altijd aaneengesloten vanaf Q0.

  • Verdeel het bereik van de potentiometer in acht even grote stukken.
  • In het laagste stuk brandt er 1 led, in het hoogste branden er 8.
  • Er brandt dus altijd minstens één led.

Situatie 2: het looplicht

Door op de knop te drukken (P0 gaat laag) schakel je over naar het looplicht. Er brandt nu precies één led tegelijk. Die wandelt van led 1 naar led 8 en begint daarna opnieuw. Met de potentiometer regel je de snelheid.

  • Potentiometer van 0% tot 100%: één stap duurt 1000ms (= 0%) tot 100ms (= 100%).

Als je opnieuw op de knop drukt kom je terug in situatie 1. De knop wisselt dus tussen situatie 1 en situatie 2.

Twee extra eisen

  • Houd je de knop even ingedrukt, dan mag er maar één keer gewisseld worden.
  • De knop moet blijven reageren, ook als het looplicht op zijn traagste stand staat. Een druk op de knop mag dus nooit een volle seconde blijven liggen.

Oplossing code

De twee situaties schuiven allebei acht bits naar buiten en latchen daarna één keer, dus ze verschillen enkel in het patroon dat ze samenstellen. Omdat de laatst verschoven bit op Q0 belandt, telt de lus af van led 8 naar led 1.

De knop lees je uit met ~knoppen & vorigeKnoppen. Zo blijft een knop die je vasthoudt maar één keer tellen, en dat is precies de eerste extra eis. De tweede eis is de reden dat de snelheid van het looplicht met millis() geregeld wordt en niet met delay(): bij een delay(1000) zou je een korte druk op de knop gewoon missen.

#include <Wire.h>

const int adresExpander = 0x38; // PCF8574AN met A0, A1 en A2 aan GND

const int pinDS = 2;   // Data ingang
const int pinSTCP = 3; // 0 naar 1 = schuifregister naar storage register
const int pinSHCP = 4; // 0 naar 1 = seriële ingang naar schuifregister
const int pinPot = A0; // Loper van de potentiometer

const int aantalLeds = 8;

bool looplicht = false; // false = situatie 1 (balk), true = situatie 2 (looplicht)
int positie = 1;        // welke led brandt in situatie 2

byte vorigeKnoppen = 0xFF;
unsigned long vorigeStap = 0;

void schrijfExpander(byte waarde)
{
  Wire.beginTransmission(adresExpander);
  Wire.write(waarde);
  Wire.endTransmission();
}

byte leesExpander()
{
  Wire.requestFrom(adresExpander, 1);

  if (Wire.available())
  {
    return Wire.read();
  }

  return 0xFF; // niets ontvangen: doe alsof de knop niet ingedrukt is
}

void risingEdge(int pinNummer)
{
  digitalWrite(pinNummer, LOW);
  digitalWrite(pinNummer, HIGH);
}

// De leds 1 tot en met aantalAan branden, de rest niet.
void toonBalk(int aantalAan)
{
  // De laatst verschoven bit komt op Q0, dus we tellen af van led 8 naar led 1
  for (int led = aantalLeds; led >= 1; led--)
  {
    digitalWrite(pinDS, led <= aantalAan ? HIGH : LOW);
    risingEdge(pinSHCP);
  }

  risingEdge(pinSTCP); // hele balk in één keer bijwerken
}

// Enkel de led met dat nummer brandt.
void toonEnkeleLed(int nummer)
{
  for (int led = aantalLeds; led >= 1; led--)
  {
    digitalWrite(pinDS, led == nummer ? HIGH : LOW);
    risingEdge(pinSHCP);
  }

  risingEdge(pinSTCP);
}

void setup()
{
  pinMode(pinDS, OUTPUT);
  pinMode(pinSTCP, OUTPUT);
  pinMode(pinSHCP, OUTPUT);

  Wire.begin();

  schrijfExpander(0xFF); // P0 hoog zetten, anders kan de knop hem niet laag trekken
}

void loop()
{
  byte knoppen = leesExpander();

  // Een knop is net ingedrukt als zijn bit van 1 naar 0 ging
  byte netIngedrukt = ~knoppen & vorigeKnoppen;
  vorigeKnoppen = knoppen;

  if (netIngedrukt & B00000001)
  {
    looplicht = !looplicht;
    positie = 1;
    vorigeStap = millis();
  }

  int potWaarde = analogRead(pinPot);

  if (looplicht == false)
  {
    // 0..1023 gedeeld door 128 geeft 0..7, dus +1 geeft 1 t.e.m. 8 leds
    toonBalk(potWaarde / 128 + 1);
  }
  else
  {
    unsigned long stapTijd = map(potWaarde, 0, 1023, 1000, 100);

    if (millis() - vorigeStap >= stapTijd)
    {
      vorigeStap = millis();
      positie = positie % aantalLeds + 1;
    }

    toonEnkeleLed(positie);
  }
}

Merk op dat de leds in allebei de situaties bij elke doorloop opnieuw geschreven worden, ook als er niets veranderd is. Dat mag: het schuifregister houdt zijn waarde vast tot je opnieuw latcht, dus je ziet geen enkel verschil. Het houdt de loop() wel eenvoudig, want er is maar één plaats waar de leds bijgewerkt worden.
