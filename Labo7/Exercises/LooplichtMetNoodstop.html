Noodstop op je looplicht

Het looplicht uit labo 1 krijgt een noodknop. Die moet werken op het moment dat je drukt, niet wanneer het je programma uitkomt. Dit is de oefening waarin de kernles van dit labo op zijn plaats valt.

Haal je Looplicht uit labo 1 erbij. De bedrading blijft exact dezelfde: vier LEDs volgens sinking op de pinnen 3 tot en met 6. Je voegt er één drukknop aan toe.

Wat je nodig hebt

De aansluitingen
Pin Waarop
pin 2 Nieuw: de noodstopknop naar de massa, met INPUT_PULLUP
pin 3 t.e.m. 6 De vier LEDs van je looplicht, sinking, elk met een weerstand van 220 Ω
Sinking, dus omgekeerd

Net als in labo 1 hangen je LEDs met de kathode aan de pin en met de anode aan de plus. Een LED brandt dus bij LOW en dooft bij HIGH. Dat blijft in deze oefening zo, ook in je ISR: alles uitzetten betekent hier alles op HIGH.

Twijfel je? Herlees Sourcen en sinken.

Wat je moet programmeren

  1. Je looplicht loopt zoals in labo 1: de LEDs branden om beurt, met een delay() ertussen.
  2. Een druk op de noodstop dooft alle LEDs, op het moment zelf.
  3. Daarna blijft alles uit. Het looplicht mag niet vanzelf weer beginnen lopen. Alleen de resetknop van je Arduino start het opnieuw.

Denk hier eerst over na

Je ISR zou er zo kunnen uitzien:

void noodstopIngedrukt()
{
  noodstop = true;   // en de loop lost het verder wel op
}

Netjes kort, precies zoals het hoort. Maar er is een probleem.

Hoe lang duurt het voor je LEDs doven met deze ISR?

Je loop() zit op het moment van de druk midden in een delay(250). Pas als die afgelopen is, kijkt hij weer naar je vlag. In het slechtste geval brandt je LED dus nog een kwart seconde na de noodstop.

Voor een looplichtje maakt dat niets uit. Voor een machine met een noodstop wel: een kwart seconde is een halve meter transportband. Een noodstop die "straks" stopt, is geen noodstop.

Zet de LEDs dus in de ISR zelf uit. Dat mag hier: digitalWrite() is een paar microseconden werk en heeft geen enkele andere interrupt nodig om af te raken. Het is precies het soort dringend werk waarvoor een ISR bedoeld is.

De vlag heb je nog altijd nodig, maar voor iets anders: om te verhinderen dat je loop() straks, wanneer zijn delay() eindelijk afgelopen is, doodleuk de volgende LED aansteekt.

De ISR doet het dringende werk, de vlag doet het beleid

Dit zinnetje uit Van pollen naar interrupts is de hele les van dit labo, en hier zie je waarom je ze allebei nodig hebt. De ISR zorgt dat het nú stopt. De vlag zorgt dat het gestópt blíjft.

Wat je moet zien

Druk op de noodstop terwijl er een LED brandt. Die LED moet meteen doven, zonder merkbare vertraging, ook al zit je programma nog midden in zijn delay(). Daarna blijft het donker.

Oplossing

De LEDs zitten hier in een array, zodat je ze in de ISR met één lusje allemaal tegelijk kan doven. Zie Arrays als dat wat weggezakt is.

const int leds[] = {3, 4, 5, 6};
const int aantalLeds = 4;

const int noodstopPin = 2;
const int stapDuur = 250;

volatile bool noodstop = false;

void noodstopIngedrukt()
{
  // Meteen alles uit. Wachten tot de loop() dat doet zou tot een kwart
  // seconde duren, want die zit op dit moment vast in een delay().
  // Sinking: HIGH is uit.
  for (int i = 0; i < aantalLeds; i++)
  {
    digitalWrite(leds[i], HIGH);
  }

  noodstop = true; // en dit verhindert dat de loop straks verder loopt
}

void setup()
{
  for (int i = 0; i < aantalLeds; i++)
  {
    pinMode(leds[i], OUTPUT);
    digitalWrite(leds[i], HIGH); // sinking: begin met alles uit
  }

  pinMode(noodstopPin, INPUT_PULLUP);

  attachInterrupt(digitalPinToInterrupt(noodstopPin), noodstopIngedrukt, FALLING);
}

void loop()
{
  for (int i = 0; i < aantalLeds; i++)
  {
    if (noodstop == true)
    {
      return; // niets meer aansteken zolang de noodstop actief is
    }

    digitalWrite(leds[i], LOW);  // aan
    delay(stapDuur);
    digitalWrite(leds[i], HIGH); // uit
  }
}
Volg eens stap voor stap wat er gebeurt bij een druk
  1. Je loop() zit in delay(250), met LED 2 aan.
  2. Je drukt. De ISR gaat af, dooft alle vier de LEDs en zet noodstop op true. Dat duurt een paar microseconden.
  3. De delay() telt gewoon verder af alsof er niets gebeurd is, en loopt af.
  4. digitalWrite(leds[i], HIGH) zet een LED uit die al uit is. Onschuldig.
  5. De lus gaat naar de volgende LED, ziet de vlag staan, en stapt met return uit de loop().
  6. Vanaf nu wordt loop() nog duizenden keren per seconde opgeroepen, maar hij stapt er telkens meteen weer uit. Er gaat nooit nog een LED aan.

Merk op dat stap 4 iets doms doet, en dat dat niet erg is. Een noodstop hoeft niet elegant te zijn, hij moet werken.

Waarom noodstop geen noInterrupts() nodig heeft

noodstop is een bool, dus één byte. Die haalt de processor met één instructie op, en een instructie kan niet halverwege onderbroken worden. Je leest hem dus altijd volledig of helemaal niet.

Bij de teller uit de vorige oefening lag dat anders, want die was vier bytes groot. Zie volatile en de vlagvariabele.
