Praktische voorbeeldtest

Dit is de opgave voor de praktische voorbeeldtest van het derde evaluatiemoment. Zo weet je op voorhand hoe moeilijk de echte test wordt.

Tijdens het derde evaluatiemoment is er ook een theoretische test. Die gaat over de leerinhouden van labo 5, labo 6 en labo 7. Oefen daarop met de theoretische voorbeeldtest.

Opgave

Bouw een motorsturing die je vanaf je pc bedient en die een noodstop heeft. De motor hangt aan een L293D, de opdrachten komen binnen over de seriële monitor, en de noodknop hangt aan een interruptpin.

Gebruik deze pinnen, en wijk hier niet van af:

  • 1A van de L293D op pin 7
  • 2A op pin 8
  • 1,2EN op pin 6
  • De noodknop op pin 2
  • De led die de noodstop aangeeft op pin 12

De motor hangt over 1Y en 2Y, op een eigen voeding, met de massa van die voeding aan de massa van je Arduino.

De opdrachten uit de monitor

Je typt opdrachten in de seriële monitor. Elke opdracht staat op een eigen lijn.

De vier opdrachten die je programma verstaat
Wat je typt Wat er gebeurt
SNELHEID:0 tot SNELHEID:255 Zet de snelheid van de motor. 0 is stil, 255 is voluit.
RICHTING:0 of RICHTING:1 Kiest de draairichting.
STOP Zet de snelheid op 0. De richting blijft staan zoals ze stond.
RESET Heft een actieve noodstop op.
  • Bevestig elke aanvaarde opdracht in de monitor, zodat je ziet dat ze aangekomen is.
  • Komt er iets binnen dat je niet verstaat, meld dat dan en laat de motor staan zoals hij stond. Een snelheid buiten 0 tot 255 hoort daar ook bij.
  • Vraag je een andere richting terwijl de motor draait, rem dan eerst af tot stilstand en keer pas daarna om.
Zet de monitor op een regeleinde

Stuurt je monitor geen regeleinde mee, dan wacht readStringUntil() een volledige seconde af of er nog iets komt. Reageert de motor pas een seconde na je Enter, dan komt het daarvan en niet van een fout in je programma. Vergeet ook de trim() niet, want anders vergelijk je "STOP\r" met "STOP".

De noodstop

  • Een druk op de noodknop legt de motor onmiddellijk stil, ook terwijl je programma aan het afremmen is.
  • De led op pin 12 brandt zolang de noodstop actief is.
  • De monitor meldt de noodstop één keer per druk.
  • Zolang de noodstop actief is, blijft de motor stil. Opdrachten mag je wel blijven aannemen, ze gaan pas in na RESET.
  • Ontdender de knop, zodat één druk ook één noodstop is.

Oplossing code

Richting, snelheid en noodstop komen alle drie uit op dezelfde pin, de enable.

Richting en snelheid zijn die van labo 5: 1A en 2A staan altijd tegengesteld, en de snelheid is een analogWrite() op de enable, die daarom op een PWM-pin moet.

De noodstop trekt diezelfde enable met een digitalWrite() laag. Daardoor werkt hij ook midden in het afremmen, terwijl de loop() in een delay() staat: de interrupt onderbreekt die delay, en digitalWrite() mag in een ISR.

Het printen gebeurt in de loop(), want Serial hoort niet in een ISR. De ISR zet alleen de vlag noodstop. De loop() ziet aan gemeld of ze de melding al gestuurd heeft, en stuurt er zo één per druk.

const int pin1A = 7;       // richtingingang A van de L293D
const int pin2A = 8;       // richtingingang B van de L293D
const int enablePin = 6;   // 1,2EN op een PWM-pin, want hier regel je de snelheid
const int noodstopPin = 2; // een van de twee interruptpinnen van de UNO
const int ledPin = 12;     // brandt zolang de noodstop actief is

const unsigned long vergrendelTijd = 200;

volatile bool noodstop = false;
volatile unsigned long laatsteDruk = 0;

bool gemeld = false; // staat de noodstop al in de monitor?
bool vooruit = true; // huidige draairichting
int snelheid = 0;    // 0 tot en met 255

void noodstopIngedrukt()
{
  unsigned long nu = millis();

  if (nu - laatsteDruk < vergrendelTijd)
  {
    return; // dit is gestuiter van de vorige druk
  }

  laatsteDruk = nu;

  digitalWrite(enablePin, LOW); // de motor meteen stil, dit mag in een ISR
  digitalWrite(ledPin, HIGH);

  noodstop = true;
}

void stuurMotor()
{
  digitalWrite(pin1A, vooruit ? HIGH : LOW);
  digitalWrite(pin2A, vooruit ? LOW : HIGH);

  analogWrite(enablePin, snelheid);
}

// Remt af tot stilstand, en stopt zodra de noodknop ingedrukt wordt.
void remAf()
{
  for (int pwm = snelheid; pwm > 0; pwm -= 5)
  {
    if (noodstop == true)
    {
      return; // de ISR heeft de enable al laag gezet
    }

    analogWrite(enablePin, pwm);
    delay(20);
  }

  analogWrite(enablePin, 0); // helemaal stil voor je omkeert
}

void verwerkOpdracht(String regel)
{
  if (regel == "RESET")
  {
    noodstop = false;
    gemeld = false;

    digitalWrite(ledPin, LOW);
    stuurMotor();

    Serial.println("Noodstop opgeheven");
    return;
  }

  if (regel == "STOP")
  {
    snelheid = 0;

    if (noodstop == false)
    {
      stuurMotor();
    }

    Serial.println("Motor gestopt");
    return;
  }

  int scheiding = regel.indexOf(':');

  if (scheiding <= 0)
  {
    Serial.println("Onbekende opdracht");
    return;
  }

  String sleutel = regel.substring(0, scheiding);
  String waarde = regel.substring(scheiding + 1);

  if (sleutel == "SNELHEID")
  {
    int gevraagd = waarde.toInt();

    if (gevraagd < 0 || gevraagd > 255)
    {
      Serial.println("Snelheid ligt tussen 0 en 255");
      return;
    }

    snelheid = gevraagd;

    if (noodstop == false)
    {
      stuurMotor();
    }

    Serial.print("Snelheid: ");
    Serial.println(snelheid);
  }
  else if (sleutel == "RICHTING")
  {
    bool nieuweRichting = (waarde.toInt() == 1);

    if (nieuweRichting != vooruit && noodstop == false)
    {
      remAf(); // eerst tot stilstand, dan pas omkeren
    }

    vooruit = nieuweRichting;

    if (noodstop == false)
    {
      stuurMotor();
    }

    Serial.print("Richting: ");
    Serial.println(vooruit ? 1 : 0);
  }
  else
  {
    Serial.println("Onbekende sleutel");
  }
}

void setup()
{
  pinMode(pin1A, OUTPUT);
  pinMode(pin2A, OUTPUT);
  pinMode(enablePin, OUTPUT);
  pinMode(ledPin, OUTPUT);

  pinMode(noodstopPin, INPUT_PULLUP); // eerst de pull-up
  attachInterrupt(digitalPinToInterrupt(noodstopPin), noodstopIngedrukt, FALLING);

  Serial.begin(9600);

  stuurMotor();

  Serial.println("Klaar. SNELHEID:0-255, RICHTING:0 of 1, STOP, RESET");
}

void loop()
{
  if (noodstop == true && gemeld == false)
  {
    gemeld = true;

    Serial.println("NOODSTOP");
  }

  if (Serial.available() > 0)
  {
    String regel = Serial.readStringUntil('\n');
    regel.trim();

    if (regel.length() > 0)
    {
      verwerkOpdracht(regel);
    }
  }
}

STOP en RESET worden opgevangen voor de indexOf(':'), want er staat geen dubbelepunt in. Zou je meteen splitsen, dan geeft indexOf() je -1 en rekent substring() met onzin. De test scheiding <= 0 vangt daarnaast ook een lijn op die met een dubbelepunt begint, want dan is er geen sleutel.

De remAf() kijkt bij elke stap of de vlag intussen omhoog staat. Zonder die test schrijft de lus na de noodstop een nieuwe PWM-waarde naar de enable en draait de motor kort verder, terwijl de ISR hem net stilgelegd heeft.
